# Nova Free Pages options and decision

## Selected: Agent launchpad

Lead with “Create your AI agent in minutes,” introduce Nova as the agent, show three plain installation steps, and demonstrate recognizable jobs. Use the existing Nova portrait as identity, strong editorial typography, luminous launch colors, and restrained technical detail. This best serves the owner’s stated audience and makes the primary action legible without prerequisite knowledge.

## Rejected: Capability atlas

Lead with the exact 27-root topology, capability groups, MIND, and named specialists. This is useful as reference material after interest exists, but it forces new visitors to translate implementation inventory into value. Reopen it only if the site’s primary audience becomes maintainers evaluating package composition rather than ordinary people deciding whether to create an agent.

## Copy and evidence rules

Outcome copy leads; exact component names appear only as secondary provenance. The package may be called free, but host/model cost is disclosed separately. “In minutes” describes the short installation path, not a measured universal completion time. The site does not claim autonomous authority, background execution, guaranteed results, formal accessibility conformance, or zero external cost.
