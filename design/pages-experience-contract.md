# Nova Free Pages experience contract

The visitor is curious about having a personal AI agent but should not need to understand skills, Faculties, orchestration, MIND, local marketplaces, or model architecture before the offer makes sense.

The page must make one promise immediately: Nova Free makes creating a capable AI agent simple, fast, and free. The agent they get is Nova—a playful, highly competent generalist ready to work on real material immediately. “Free” describes the Nova package; any compatible host or model charges remain separate and must not be concealed.

The arrival path is overview → see recognizable outcomes → get Nova Free → choose the host-specific installation route → start a new task and talk to Nova. Failure and recovery route to installation detail, troubleshooting, support, and rollback guidance without deleting prior state.

The site is a static responsive GitHub Pages artifact. It must remain operable with keyboard, pointer, and touch; preserve a skip link, native landmarks and links, visible focus, text wrapping, reduced-motion behavior, and readable narrow layouts. It may use existing first-party Nova artwork only. No remote fonts, analytics, tracking, account creation, fake testimonials, invented metrics, or unqualified accessibility, popularity, security, or outcome claims.

Done means the primary promise and action are obvious at a glance; the first screen introduces Nova rather than internal architecture; capability copy describes jobs and results before implementation names; installation is presented as three understandable steps with exact advanced commands available; all required pages and local links pass deterministic inspection; and the actual site is inspected at representative wide and narrow browser sizes before deployment.
