# Install Nova Free 4.3.2 on a Claude-compatible host

Extract `nova-the-optimal-ai-free-4.3.2-claude.zip`. Its extracted root contains `nova-the-optimal-ai`, `folders` and `zips`. The complete plugin is `nova-the-optimal-ai`, with `.claude-plugin/plugin.json` and all 28 skills inside it. This host-specific download has no additional `claude` folder. A full source/staging kit places these same entries under its `claude` directory.

Give the complete plugin folder to the installing agent. Use the live host's supported local-plugin route, preserve existing tools and user work, and resolve any governing Nova conflict within the user's actual authority. Keep all resources, licenses and notices together.

If the host accepts only individual Agent Skills, `folders` and `zips` supply detachable skills. Each carries a `nova-free-rights` directory with license, attribution, notice, trademark policy, provenance and applicable component notices. Keep that envelope with the skill. A selected subset does not establish complete-edition behavior.

Confirm discovery of Nova Free 4.3.2 and the intended enabled state, apply the host's required refresh or restart, then invoke Nova on a small real task. A compatible folder does not prove the host loaded it. If the layout is unsupported, preserve the error and use the [troubleshooting guide](TROUBLESHOOTING.md); do not claim an installation from source parity alone.

Persistent services remain optional. They require Python 3.10 or newer available to the harness and an owner-authorized data root outside the plugin. Follow [Upgrade](UPGRADE.md) to retain earlier work and a rollback route.
