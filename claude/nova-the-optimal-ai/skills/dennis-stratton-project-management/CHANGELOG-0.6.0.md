# Version 0.6.0

Project Bridge adds a read-only, source-linked route through outcomes, commitments, declared dependencies, and completion evidence; an actual host refresh and change comparison; durable reading preferences; and a fictional community exhibition walkthrough. This changes the supported user workflow from native record administration to guided project reading, so it is a product update from 0.5.1 to 0.6.0.

The update preserves the Dennis project-control engine, schemas, authored operating guidance, useful examples, and native command-line tools. The obsolete web record-editor adapter is replaced by a compatibility launcher. Browsing through Project Bridge does not write native project records.
