# Project Bridge

Project Bridge is a local read-only reader for Dennis project-control records. Start it with Open Project Bridge.cmd on Windows or Open Project Bridge.command on macOS or Linux. On Windows, Create Project Bridge Shortcut.vbs adds a quiet desktop icon using the included Dennis ICO. Python 3.10 or newer is required.

The portfolio connects project purpose to its phases, milestones, and commitments. Select a station to see what it enables, its next recorded move, declared dependencies, completion criteria, and linked evidence. Dependency links show only IDs present in the native record; they do not imply sequence duration or a critical path. Use Refresh project to read the current native state.

The fictional community exhibition walkthrough demonstrates an accessible visitor route, a confirmed venue installation slot, installation readiness, a public opening, and an explicitly unknown supplier delivery date. It is a sample, not a real project. It never creates or saves a native project record.

Evidence opens from the exact supplied source locator when that file is within the record folder or an explicitly declared source-authority folder. If the source cannot be read as text, the reader offers the exact original file when available; it does not fabricate extracted content.

The companion stores only viewing position, selected station, theme, and comparison snapshots in a separate local preferences folder. It does not write native project records. Use scripts/project_control.py for authorized native project-state work. Exit stops the local reader and leaves this browser tab inert.
