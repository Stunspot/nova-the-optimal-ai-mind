Nova Operations setup instructions own the package shape and governed Continuity
launcher. This component update does not require a second standalone package or a
particular dreaming companion.

and links worth returning to." Worldline surveys retained occurrences across the
permitted user/agent boundary; project and conversation filters are optional. The
same `worldline_timeline.py` library and CLI contracts are documented in
`../scripts/README.md`, alongside the retained legacy project views.

`NOVA_CONTINUITY_HOME`, outside the installed skill/plugin directory and host cache.
Use the edition's registry-backed launcher for Nova state. Generic explicit
component workspaces remain governed by the existing selection contract. Reads
must not silently initialize, migrate or import a store.

Retain ordinary/off capture policy only from the customer's setup choice or
standing direction, with its source. Established ordinary authority permits
small event captures at natural transitions without repeated consent prompts;
private-topic and current no-retention directions suppress capture. Observe a
transaction receipt before claiming persistence.

Host discovery, model invocation, scheduling, filesystem access and external-action
authority are capabilities to observe in the target installation. Source and
package checks do not establish them, and a skill instruction is not a background
capture daemon. Follow the edition's bounded first-run verification.
