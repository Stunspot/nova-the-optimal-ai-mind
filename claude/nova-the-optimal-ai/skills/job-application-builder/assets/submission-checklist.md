# Optional private handoff checklist

Apply only the checks that matter to the actual requested documents. This checklist is a reminder, not authenticated approval or a substitute for a current snapshot review.

## Match the actual vacancy

Confirm employer/role, the supplied posting's coverage and currency, required versus preferred criteria, selected documents and their allowed formats/limits. Preserve unresolved deadline wording and time zone. Exclude forbidden attachments. Do not invent an application question or make an optional letter compulsory.

## Inspect the current documents

Compare actual source meaning with every material claim, including identity, dates, education, titles, scope and metrics. Describe adjacent experience honestly. Keep unsupported claims, private gap notes, source ledgers and confidential data out of applicant-facing files. Confirm work-sample sharing permission and label simulations. Inspect the actual rendered format and upload preview separately when text export is insufficient.

## Review and applicable authority

Record only the agent or user review that actually happened, with its current snapshot and basis. An agent review is not human approval. Carry existing applicable user authority through the work; do not request the same permission again merely because the task resumed. User-only attestations require the user's actual answer, and sensitive disclosure choices remain theirs.

## Distinguish an intended handoff from an observed submission

Record not-submitted while preparing documents. After an authorized external action, retain the actual authority reference, observation time and receipt reference. If the action times out or its outcome is unknown, preserve that state and check whether it arrived before retrying. This skill's native scripts never submit or authenticate a receipt. Do not tick mutually contradictory states to make a case appear complete.
