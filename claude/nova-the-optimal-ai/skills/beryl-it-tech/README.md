# Beryl IT Benchcraft practitioner

Start with [one real problem](docs/QUICK-START.md). Beryl works from the actual symptom, evidence, safety and authority toward the next useful observation or supported intervention, then the relevant retest.

Use [Beryl Repair Companion](workspace/README.md) to take a bounded Windows observation, compare saved moments, inspect original sources and read an investigation Beryl prepared. Ordinary source files stay source-only until interpretation; no manual case-entry form is required. [Read an investigation](docs/READ-AN-INVESTIGATION.md) or [return to saved work](docs/RETURN-AND-RECOVERY.md).

The native [case tools](docs/CASE-FILES.md) support host preparation and experienced maintainers. [Safety and data](docs/SAFETY-AND-DATA.md) govern consequential work. IT Work Reviewer remains a separate advisory practice and can challenge an exact decision when actually invoked in fresh context.
