# Fixed Windows observation authority

Checked official Microsoft references on 2026-10-16 UTC for the planned read-only observation. These define the actual fields; they do not establish a fault or successful repair.

[GetSystemTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getsystemtimes): idle, kernel and user counters are100ns ticks; kernel includes idle. CPU busy percentage over the chosen interval is100*(deltaKernel+deltaUser-deltaIdle)/(deltaKernel+deltaUser). Counter errors/reset/zero interval yield unavailable, never a zero load. More than64processors narrows the return to the calling thread's primary processor group; expose this scope or conservatively withhold whole-PC CPU comparison. Do not claim application attribution, thermal state or latency.

[MEMORYSTATUSEX](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/ns-sysinfoapi-memorystatusex): initialize dwLength, retain ullTotalPhys and ullAvailPhys in bytes. Available physical memory includes reusable standby/free/zero memory. Approximate load is not a leak or paging diagnosis. Never label process-specific pagefile limits as whole-system committed memory.

[GetSystemPowerStatus](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getsystempowerstatus) and [SYSTEM_POWER_STATUS](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-system_power_status): unknown values are255;128means no system battery. Test unknown before bit flags. Battery percentage is0–100orunknown; AC is online/offline/unknown. No battery-life prediction or power-policy mutation is needed.

[GetDiskFreeSpaceExW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getdiskfreespaceexw): returns per-caller available bytes and per-caller total under quotas, plus total free volume bytes. Label the selected value as space available to this account; keep64-bit values. Query only the system volume returned from [GetSystemDirectoryW](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getsystemdirectoryw); no drive enumeration, benchmark or user content reads. This is capacity, not disk health or speed.

Use ctypes with declared argtypes/restype and use_last_error=True, no shell command strings. Direct return/error and captured timestamps establish observations only. Fixed supported Windows sampling can run in an owned bounded child for cancellation/timeout. The companion's state transition owns publication; cancelled/superseded children cannot publish results late. Leave host/machine identity explicit and avoid leaking usernames or credentials. Tests should contrast valid values with unknown/failed/cancelled results, plus one actual read from this Windows machine; never inject synthetic values into a live result without labeling the test.

Implementation additions checked 2026-10-16: [GetVolumePathNameW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getvolumepathnamew) resolves the system directory to its volume root without enumeration; [GetComputerNameW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getcomputernamew) supplies the computer-name continuity hash; [GetActiveProcessorGroupCount](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getactiveprocessorgroupcount) prevents a partial group reading being labeled whole-PC CPU. The raw computer name is not retained.
