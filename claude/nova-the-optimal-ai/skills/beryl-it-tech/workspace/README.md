# Beryl Repair Companion

Catch what changes while a computer problem happens, compare two useful moments, or read the investigation Beryl prepared beside its sources. You can start with the fixed Windows observation or an existing log, screenshot or photo. No manual case-entry form is required.

From the Beryl skill folder run `python -B workspace/launch.py`, or use Open.cmd on Windows, Open.command on macOS, or Open.sh on another supported desktop. Python 3.10 or newer is required; no third-party Python packages are needed. On Windows, `python -B workspace/install_shortcut.py` creates Beryl Repair Companion. The live observation is Windows-only; reading prepared work does not require it.

[First use](../docs/FIRST-USE.md) connects the real controls to a useful result. [Observation limits](../docs/OBSERVATION-LIMITS.md) explain what the small sample can and cannot establish. [Read an investigation](../docs/READ-AN-INVESTIGATION.md) follows evidence, rival explanations, exact sources and review. [Return and recovery](../docs/RETURN-AND-RECOVERY.md) preserves the whole saved folder.

The assistant uses [HOST-PATHS.md](HOST-PATHS.md) for exact local inspection and publication. The app copies that route into the existing conversation; it sends no message, calls no provider and runs no proposed command. **Refresh prepared work** reads actual publication while retaining the selected revision. Earlier work stays labelled.

Choose **Exit** and wait for **Beryl is closed**. Cancel an observation first if one is running. The known saved home, prior native work.json, original attachments and new bench store stay outside replaceable program files.
