# Giles material artwork

These three original bitmap assets were generated for this application with imagegen on 2026-10-03. They are reusable interface material art, not UI mockups or data visualizations. Source content, catalog nodes and relationship edges are rendered by functioning application code.

atlas-material.png: smoked oak, worn leather and an engraved archival instrument; light and quiet zones serve collection discovery and source reading.
blackglass-material.png: a thick smoked-glass slab, machined bevel and localized optical signal; the reading instrument carries the same material language.
mirrorloop-material.png: original peripheral mirror facets composed with quiet working space, using the viewed Scrapbook MIRRORLOOP artwork as a style reference. The original reference pixels are not distributed.

The Blackglass Crimson application image and other Scrapbook pictures informed design reasoning. Their source records remain private and unchanged. All runtime asset paths are local, explicit HTTP routes; the application does not depend on the user's Scrapbook or a remote asset host. Material and inspection decisions are recorded in ../DESIGN.md and the three theme records.
