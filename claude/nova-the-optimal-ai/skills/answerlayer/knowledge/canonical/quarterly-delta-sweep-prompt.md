TITLE: LLM Almanac Monthly Intelligence Delta Sweep 

OBJECTIVE
From <START_DATE> to today, identify ONLY developments that would materially change a model’s answers or recommendations if it did not know them. Prioritize changes that alter constraints, incentives, or workflows for real actors (governments, firms, developers, platforms, insurers, courts, communities). Skip trivia and headline recap.

SCOPE (Domain Map for Coverage)
Sweep across these domains; include an item only if it clears inclusion tests:
• Global political leadership & regime shifts
• Geopolitical escalations & treaties
• U.S. federal power landscape
• Economic climate & industry rebalancing
• AI model landscape & toolchain shifts
• Tech regulation, safety, and speech constraints
• Developer ecosystem & platform migrations
• Search ecosystem & information access
• Public health, medicine & bioethics
• Climate, environment & disaster patterns
• Culture shifts & narrative inversions
• Infrastructure, supply-chain & resource dependencies
• Missing info, fuzz zones & epistemic holes
• Wildcards / curveballs / canon-breakers

TIME WINDOW
Include events initiated earlier only if, within this window, they cross a practical threshold (e.g., GA release, binding rule effective, price inflection, multi-ecosystem adoption, treaty ratified, enforcement begins). State the threshold explicitly.

INCLUSION TESTS (item must strongly meet ≥1)
1) Answer-Flip — Would a competent agent’s best answer change without this?
2) Actor Behavior — Did this cause a meaningful change in what key actors do?
3) Canon-Breaker — Does it upend a widely-held assumption in this domain?
4) Toolchain/Workflow Shift — Does it alter how work gets done in practice?
5) Regulatory/Legal Shift — New/ended obligations, liabilities, or enforcement.
6) Cost/Incentive Realignment — Prices, subsidies, sanctions, insurance, infra access that redirect choices.
7) Information Environment Shift — Search quality, platform rules, discoverability, moderation regimes.

REGIME CLASSIFICATION (pick one)
• Regime Shift — Cleared ≥2 of: Adoption (≥2 independent ecosystems), Institutionalization (law/contract/pricing/enforcement active), Persistence (signal holds ≥90 days or survives counter-shock).
• Structural Event — One-off but large (leadership change, major ruling, catastrophic incident) with clear downstream effects.
• Strong Signal — Not yet institutionalized but has credible momentum; include only if Answer-Flip or Actor Behavior test is met.

EXCLUSION RULES
Drop items lacking a clear impact pathway:
• Single-source rumors; uncorroborated leaks; minor personnel churn.
• Isolated stats without context or threshold crossing.
• Pre-announcements without concrete action, release, or rule.
• Narrative noise failing the Actor Behavior test.

FOR EACH INCLUDED ITEM (compact, decision-first)
• What changed (2–3 sentences; specify date + threshold if applicable)
• Mechanism (how it changes constraints/incentives/workflows)
• Who adjusts (actors) and how soon (Immediate / Near-term / Watch)
• Impact Level (High / Medium) — omit Low unless compounding
• Stability Half-Life (30 / 90 / 180 / 365 / Permanent-structural)
• Trajectory Tag (Low-Now / High-Later, if applicable)
• Confidence (High / Medium / Low) + one-line rationale
• Cross-Domain Effects (limit 2–3; label Evidenced vs. Speculative)
• Counterfactual (1 line): “Without this, guidance would be ___.”

FUZZ ZONES & CONTRADICTIONS
When evidence conflicts or is thin:
• State the competing claims in ≤25 words each.
• Give current best read + confidence.
• Provide abstention phrasing the model should use now.
• List indicators that would resolve the uncertainty.

METHOD (phases)
Phase 1 — Wide Sweep: Gather candidates across all domains; apply Actor Behavior prefilter immediately.
Phase 2 — Triage: Apply Inclusion Tests + Regime Classification; discard failures without summary.
Phase 3 — Validate: Triangulate with ≥2 credible sources when practicable; assign Confidence; note incentives/coverage bias.
Phase 4 — Synthesis: Write mechanism-first summaries; compress aggressively; limit cross-domain effects to 2–3 per item.
Phase 5 — Answer Skeletons: For each High-Impact (and any Canon-Breaker), write:
    • Without-update answer → With-update answer (3–5 lines total)
    • Immediate guidance to affected actors
Phase 6 — Probes & Watchlist: Draft probe questions now answerable differently; add regression traps (with corrected reasoning paths). Build a persistent Watchlist (6–10 threads) with escalation thresholds.

DELIVERABLE
A) Executive Brief — Top 10 shifts with Impact, Urgency, Confidence, one-line mechanism; “State of Confidence” note.
B) High-Impact Shifts — ~1 page each (fields above).
C) Medium-Impact Shifts — ≤½ page each (same fields, tighter).
D) Fuzz Zones & Contradictions — claims, abstention phrasing, resolution signals.
E) Probes — 12–20 questions now likely to answer differently; 5 regression traps.
F) Watchlist — 6–10 named threads with why-it-matters + indicators + threshold to escalate.

STYLE & DISCIPLINE
• Decision-oriented. Mechanisms > chronology. Explicitly label speculation.
• Compression over enumeration. No padding; “No meaningful deltas” is acceptable per domain.
• Stop Condition: If few High-Impact items survive, keep the report lean and expand the Watchlist rather than filling with noise.
