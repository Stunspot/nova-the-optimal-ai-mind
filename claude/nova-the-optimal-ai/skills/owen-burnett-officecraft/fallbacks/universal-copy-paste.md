# Officecraft production packet

Use this packet in any chat or host that lacks the normal skill relationships or file-production tools. It preserves the office-production judgment and produces a handoff another capable environment can execute.

## Begin the job

Turn the supplied material into a compact brief. Infer ordinary presentation choices. Ask one focused question only when it changes audience, factual meaning, source or template authority, artifact family, editability, privacy, compatibility, or external delivery.

## Hold one content spine

Create a ledger for the items that must agree across files. Mark each as supplied, verified, inferred, illustrative, conflicted, or open. Keep a calculation's source, period, unit, and denominator with the value. Update the ledger before revising a deck, document, workbook, or PDF derivative.

## Produce the appropriate specification

### Editable document

Give a title, heading ladder, lead recommendation, section outline, prose/bullet/table choice for each section, source treatment, page/typographic direction, accessibility notes, and page QA checklist. Keep tables for comparable records and use semantic headings/lists.

### Presentation

Give a slide map. For every slide specify its audience takeaway, headline, evidence, visual form, speaker support, and connection to the next slide. Keep one principal message per slide and name the intended decision or next action.

### Spreadsheet

Define sheets, column meanings, units, data sources, assumptions, formulas, outputs, and chart requirements. Separate raw data from calculations. State formula checks, reconciliation tests, and any native recalculation still needed.

### PDF / final handout

Choose direct composition or an editable parent. Specify page order, fixed reader intent, source relationship, export settings where known, visual checks, link/metadata checks, and the approval boundary.

## Run a task-facing review

Check the packet for factual consistency, names/dates/units, source ownership, source-to-derivative lineage, visual hierarchy, readable tables/charts, accessibility cues, privacy residue, editability, and the status of each claimed check. State what was actually created or inspected in this host. Keep external sharing, emailing, upload, overwrite, and approval with the accountable owner.
