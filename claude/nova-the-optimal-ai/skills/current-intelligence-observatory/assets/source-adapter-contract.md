# Source adapter contract

An optional source adapter may discover or retrieve public evidence, but it must emit the Observatory's shared records rather than create a private silo.

- Adapter ID and version
- Source family and authority basis
- Access route and terms
- Inputs and secrets required
- Rate and scope limits
- Discovery output
- Capture output and receipt fields
- Failure and retry states
- Time fields and canonical URL behavior
- Personal-data minimization
- Content-instruction isolation
- No external mutation without separate authority
