# Save only the work the next session needs

A short rehearsal can end in chat with a useful cue, one unresolved behavior and a next question. For a maintained packet, retain the original response and sources before polishing. Choose a private folder outside the installed skill; copy the example only as a labelled fictional demonstration, never as the user's history.

| Current artifact | Job |
| --- | --- |
| employer-role-brief.md | Role, actual instructions, logistics/unknowns and source-linked criteria |
| criteria.csv; question-map.csv | Priorities, criterion-to-source basis, question meaning and probability labels |
| source-register.csv; source-evidence.csv | Source identities and inspectable retained excerpts/copy hashes |
| evidence-register.csv; evidence-support.csv | Claim-specific support, self-report distinctions and unresolved conflicts |
| answer-bank.md | Adaptable question cues, correct evidence and support state |
| practice-record.json | Original attempts, provenance, scope, exact behavior drills and bounded coverage |
| mock-session-record.md; critique-and-drills.md | Readable response/feedback story with explicit fictional or observed provenance |
| questions-to-ask.md; final-interview-brief.md | Useful unknowns, compact cues, honest limits and next action |
| packet-review.json plus its report | Actual semantic/context review bound to current packet bytes |

The current checker qualifies only a consistent reviewed packet, not a person's employability. It never generates approval or a content review. See [Saved practice format](saved-practice-contract.md) for exact states, migration and helper commands. Source excerpts establish inspectability; only judgment can decide whether a particular claim follows.

## Return and recovery

Before editing, retain a dated copy of the private packet. Keep raw user words intact; make revised demonstrations separate. On return, compare recruiter instructions, role, source facts and answer wording. Current attempts are scoped to the preparation they used. Changed context makes them historical; it does not erase them or prove failure. Repair affected facts and practice only the behavior that needs a new observation.

The readiness record holds the next concrete action and unobserved areas. A useful resume prompt is: “Open this private packet, compare the current role instructions with the saved scope, preserve prior responses, and resume the next unresolved drill. Ask one question and wait.”

A missing file or failed checker does not authorize deleting the folder. Restore the missing original from the saved copy, correct the named row or downgrade the claim. `--draft` permits inspection of incomplete material while explicitly withholding qualification. Without Python/files, retain the same distinctions directly in conversation and say the native checks were not run.
