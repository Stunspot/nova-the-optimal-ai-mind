# Claude Code Adapter

Place the complete SKILL folder where Claude Code loads project or user skills, preserving references, assets, examples, and scripts. Invoke the SKILL by name. The calculator and router use Python's standard library. Local routing works only when Claude Code can reach Ollama on the same machine, and execution retains the dual authorization gate. If execution is unavailable, keep the route as a plan and disclose the lost local-run guarantee.
