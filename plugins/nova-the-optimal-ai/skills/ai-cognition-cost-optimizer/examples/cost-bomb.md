# Example: Cost Bomb

An agent repeats a failed formatting repair while context grows every turn. Cost velocity crosses the workflow warning band and the same state hash appears three times.

Cognition Economist stops recommending further paid attempts, preserves route, token, retry, parser, and state-hash evidence, and proposes halting the workflow. It does not revoke the key or terminate the production job without authority. The incident becomes a bounded retry-budget regression case.
