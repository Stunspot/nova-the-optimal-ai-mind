# Example: Local Is Cheap Cash, Not Free Economics

The user already owns a GPU, so the cash comparison includes measured power and maintenance but no new hardware purchase. The fully loaded comparison also includes amortization, setup time, lower throughput, and operator attention. Both views are useful; neither is smuggled in as the only truth.

The local route remains eligible for private overnight consolidation. The API route remains preferred for high-consequence live work because the local model has not passed that workload's quality gate. The output recommends testing the local route on delayed low-risk jobs rather than declaring one universal winner.
