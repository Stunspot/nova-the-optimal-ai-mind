# OMNARA Reading Room 1.5.0

Understand what your saved research rests on. The room opens an inquiry report beside its citations and retained source notes. It supports two-source comparison, inquiry search, return to the report reading place, refresh and historical reading, three visual environments and a private offline HTML export.

## Open

Run `Open.cmd` on Windows or `python3 workspace/open.py` on macOS or Linux with Python 3.10+. `OMNARA_HOME` selects an existing research home; `--data-root "your folder"` selects one for a single launch. Nova resolves its default from the active estate research folder; portable installations fall back to Documents/OMNARA Campaigns. Reopen with the launcher after reboot.

## Ordinary reading

Choose an existing inquiry or the labeled worked example. Follow report citations to the source record. The room shows what note was retained, its scope and any recorded web original. A note does not imply the full original was archived. Compare two sources or search the inquiry; return from a result to its report context. Refresh after research changes to load the new report and review binding while keeping a supported prior reading view available.

Room preferences and reading history are separate from native campaign records. Browsing, refresh and Exit do not rewrite the native report, source notes or review. A prepared continuation request is copy-only and makes no provider call. See [the customer room guide](../docs/CAMPAIGN-ROOM.md), [the first-use guide](../START-HERE.md) and [the complete native research skill](../SKILL.md).

The detailed research skill, campaign engine, source and claim tools, review contract, author persona and all themes remain part of the complete package. This room is a reader for saved evidence; it does not conduct web research or certify source-to-claim entailment.
