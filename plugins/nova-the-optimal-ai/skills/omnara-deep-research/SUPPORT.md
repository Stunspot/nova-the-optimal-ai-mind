# Support

Use [GitHub Issues](https://github.com/Stunspot/omnara-deep-research/issues) for reproducible defects, documentation problems, helper failures, and bounded feature requests.

Before opening an issue:

1. remove secrets, private source content, personal data, and paid-access material;
2. record the Omnara release or source commit;
3. name the host, operating system, Python version when relevant, and installation route;
4. include the exact command or prompt, observed result, expected result, and complete error;
5. state whether the failure concerns placement, installation, discovery, invocation, helper execution, research quality, or publication.

Use [GitHub Discussions](https://github.com/Stunspot/omnara-deep-research/discussions) only if enabled. If it is unavailable, use an issue.

Security-sensitive reports must not be posted publicly. Follow [SECURITY.md](SECURITY.md).

This project is maintained on a best-effort basis. No response-time or service-level commitment is implied.
