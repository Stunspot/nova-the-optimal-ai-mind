# Follow a real research result

Open [the sea-level comparison report](sea-level-comparison/report.md), then inspect its source notes and claim ledger. It is a focused source-method inquiry conducted during this repair, not a station-data analysis or an independent model trial. The sources are live URLs; the included notes preserve what was read, not full archived originals.

Practice the decisive distinction: a local tide-gauge trend is negative while a global satellite curve rises. Before reading the answer, say whether this is a contradiction and identify the missing comparison facts. Feedback: a shared sea-level topic is insufficient. Ask about the land-relative reference, vertical land motion, spatial aggregation and matching record period. The observed disagreement alone does not locate an error in either series. Do not infer a station's actual cause without station-specific data.

Now change the task: an engineer wants a future local flood-design threshold. Does the same report verify that decision? No. Its evidence explains measurement differences; it does not supply future scenarios, a design horizon, site data or an engineering criterion. Ask for the task-specific projection and site context instead of recycling the earlier verdict.

For re-entry, copy the example into a research home before editing. Open the copied campaign through Import native vault. If a source note changes, the room shows unestablished current review. Set the campaign back to review/active, inspect the changed material, amend the report when warranted, and record an actual new review. The old report may remain a useful historical answer even when its currentness has expired.
