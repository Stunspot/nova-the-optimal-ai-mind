# Current limitations

Omnara is designed to make evidence boundaries visible. These are the boundaries of this standalone repository and its helpers.

## Activation is host-specific

This source tree is an individual skill, not a standalone Codex plugin marketplace. The repository does not provide or verify one universal installation command. A host must support skill import, or Omnara must be used through a package such as Nova.

## The scripts do not conduct research

The Python helpers create and validate campaign state, assemble Markdown, and check structural citation integrity. They do not search the web, open sources, judge source quality, or write the semantic review.

## Structural citation integrity is not entailment

A passing citation audit confirms that markers and eligible evidence records resolve. It does not confirm that a source supports the exact claim, causal language, number, population, scope, or date used in the report.

## Source quantity is not coverage

The default budgets are ceilings, not targets. Hundreds of discovered URLs can still represent one source lineage or leave a high-importance locus untouched.

## Durable memory depends on files

The campaign vault provides resumable state only when the host can retain and update files. In a plain chat without durable files, Omnara can produce a bounded research packet but cannot honestly claim a resumable exhaustive campaign.

## Access limits can bias the corpus

Unavailable browser rendering, PDFs, private databases, authenticated sources, or local files can weaken coverage. Omnara records those limits; it cannot erase them through confident prose.

## No automatic paid or authenticated fallback

Paid, private, authenticated, or externally mutating access requires explicit user authority. Omnara should not silently switch routes to satisfy a depth request.

## No formal accessibility or conformance claim

The Markdown source has received structural lint and manual documentation review. This does not establish WCAG conformance, screen-reader compatibility across all renderers, representative-user success, or legal compliance.

## No universal truth guarantee

The method improves source custody, contradiction handling, and auditability. Conclusions remain bounded by the searched corpus, evidence quality, access, time, reviewer competence, and disclosed uncertainty.
