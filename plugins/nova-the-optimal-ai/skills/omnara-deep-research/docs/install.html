Nova Free or Emergent

Use the current edition package's own install/update instructions. Omnara is included as a maintained component. MIND is integrated architecture; the retired standalone MIND plugin is not required. See the exact installation guide for complete individual-skill and fallback routes.

Claude-compatible skill host

Download the Omnara release ZIP or Omnara per-skill ZIP included in your current Nova edition. Upload it through the host's skill manager, enable it, and start a new conversation. This route carries the individual skill; it does not claim identical host behavior.

Open and return to the campaign room

Extract the complete package and run Open.cmd on Windows or python3 workspace/open.py on macOS/Linux with Python 3.10+. Research lives outside the application. The room guide explains the library, environments, saved notes and return path.

Other skill-capable hosts

Import the complete skill directory according to the host's current instructions. Do not copy only SKILL.md: the skill depends on its personas, references, knowledge, fallbacks, assets, schemas, and scripts. This project does not claim one universal path or CLI command.

Plain-chat fallback

Copy the complete universal workflow into a new conversation, then append your request. This preserves the method but loses automatic discovery, bundled-file loading, persistent campaign files, and unexercised tool integration.

Verify discovery and invocation

In a fresh task or conversation, ask the host to list the skill named omnara-deep-research and return its display name. Expected: OMNARA Deep Research.

Use $omnara-deep-research. Frame a campaign for deciding whether our small product team should adopt passkeys in 2026. Do not browse yet.
