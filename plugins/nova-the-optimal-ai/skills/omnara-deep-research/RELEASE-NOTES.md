# OMNARA Deep Research 1.5.0 — Reading Room

Baseline: standalone 1.4.0. This update adds a report-first way to read existing research beside its evidence. Open an inquiry, move from a cited report passage to its retained source note, compare two source records, search for a passage, then return to the same reading position. A private HTML copy can be previewed and opened offline; its web references still require a connection.

The room reads the existing native inquiry, report, source and claim records without editing them during browsing. It distinguishes retained notes from complete originals and live web links. When report or source bytes change, refresh reads the new version, marks the old review as historical, and preserves a supported earlier reading view. Reading position, selected source and room appearance remain separate from native research records. A prepared continuation request is copy-only and is not sent to an AI provider.

The research skill, persona, promptcraft, evidence contract, campaign format, authored examples, three visual themes, and detailed native research tools remain included. The agent still does the research and owns evidence judgments; the Reading Room makes the saved argument easier to inspect.

## Release boundary

The standalone ZIP is a source candidate until its exact hash is frozen and independently reviewed. A local source/package check does not establish broad host compatibility, semantic research quality, public delivery or installation. Existing Nova Free and Nova Emergent edition membership remains part of the coordinated estate release; this ZIP does not update either parent package or shared shelf metadata.
