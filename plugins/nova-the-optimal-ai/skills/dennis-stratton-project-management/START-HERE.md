# Project Bridge 0.6.0

Project Bridge helps you see what your projects need next. Follow a commitment back to the outcome it serves, inspect declared dependencies, open the evidence behind a decision, and compare the current project record with an earlier reading.

## Open it

On Windows, double-click **Open Project Bridge.cmd**. For a quiet desktop icon, run **Create Project Bridge Shortcut.vbs**; it creates **Project Bridge.lnk** with the included Dennis icon and a hidden-window Python launcher. On macOS or Linux, run **Open Project Bridge.command** from this folder. Python 3.10 or newer is required. The reader opens in your browser on this computer; it does not contact an outside service.

At first launch, use the selected project-record folder or choose the folder that contains your Dennis project records. The included community exhibition is a fictional walkthrough. It demonstrates an accessible visitor route, an installation commitment, a genuine recorded dependency, and a supplier date that remains unknown. It does not create or change project records.

## Read a project

Choose a project to see its intended outcome, current purpose connection, next action, and unresolved decision. Select a commitment in the route to read what it enables, what is declared as a dependency, what would count as completion, and which source supports it. A parent-child link shows the record's hierarchy; only an explicitly recorded dependency is shown as a dependency.

Open source material from the selected commitment. Safe text files can be read in the app. When a supplied original is a format the reader does not extract, use **Download exact original** to get the unchanged file. If a source is unavailable, the reader says so and offers refresh or reconnect actions when appropriate.

Use **Refresh project** to read the latest host-published project state. The comparison shows earlier and current values when a real revision is available. Unknown dates and forecasts remain unknown; the reader does not invent a duration, completion percentage, or critical path.

## Your records and reading position

Project Bridge is read-only for project records. Selecting a station, opening evidence, changing appearance, or leaving the app does not publish or edit project state. Your selected project, station, appearance, scroll position, and local comparison snapshot are saved in a separate preferences folder on this computer.

Use the Dennis native `scripts/project_control.py` tools for authorized project-record changes. Project Bridge does not replace those tools or become another project database.

Choose **Exit** in the app to stop its local reader. The browser tab then shows a closed screen with its actions disabled. Start the shortcut again to reopen it.
