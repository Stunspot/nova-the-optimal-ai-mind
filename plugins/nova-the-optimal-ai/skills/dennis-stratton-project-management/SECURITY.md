# Security

Report a suspected Dennis Stratton Project Management security issue privately to [contact@collaborative-dynamics.com](mailto:contact@collaborative-dynamics.com).

Include:

- affected product version and package type;
- host and operating-system version;
- the smallest safe reproduction;
- observed impact;
- relevant file names and hashes; and
- any safe mitigation already identified.

Do not include credentials, tokens, private keys, personal data, proprietary project records, private repository contents, or exploit details in the initial report.

Version 0.3.0 is an instruction package with an optional local Python CLI. It is not a security scanner, identity provider, access-control system, project-management service, or authorization mechanism. A generated plan or validated record does not grant permission to access, modify, publish, deploy, or disclose anything. The optional CLI may create or update the centralized record estate only at the resolved authorized path; review permissions, backup, and retention for that path before use.

Reports are acknowledged when the private maintainer channel is available. This release makes no response-time or remediation-time commitment.
