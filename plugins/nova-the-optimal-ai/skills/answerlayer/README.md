# AnswerLayer 0.5.0

Bring your assistant the answer someone relies on and the new information that might change it. AnswerLayer helps establish what the development actually affects, what wording or action should change, what remains uncertain, and what would justify another look.

For example: “We recommend option A because of X. This new source says Y. Does that change the recommendation, its confidence, or only when we should act?” Supply or point to the original answer and source material; the assistant does the comparison with you.

Start with [the skill](SKILL.md). When the work needs durable evidence or exact patch history, the assistant can use [the native tools](knowledge/native-ledger-reference.md). Narrow comparisons can stay in the conversation. Historical source material remains preserved and explicitly dated.

There is no separate AnswerLayer companion app in this release. Existing native files and previous app work remain yours; see the bundle's RETIRED-APP.md for recovery locations. Native v2 records keep their existing format.
