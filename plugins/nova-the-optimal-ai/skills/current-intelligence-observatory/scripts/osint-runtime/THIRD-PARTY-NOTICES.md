# Optional OSINT tools

Setup retrieves pinned upstream source archives for theHarvester (GPL-2.0-only) and SpiderFoot (MIT), preserving their original licenses. Maigret 0.6.6 and Shodan 1.31.0 are installed from their MIT-licensed Python distributions. Dependencies retain their own package licenses. These separately installed tools retain their upstream licensing.

The Maigret site database derives from https://github.com/soxoj/maigret at d7f83f9b7ce9956cef1a9c2e41bece8796b13fa8. The passive-source catalog derives from https://github.com/laramies/theHarvester at 49a38f8d33c32336bbf6a111ea723ea223116265. Generated configuration contains no credentials.
