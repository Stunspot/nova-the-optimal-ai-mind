# Watch specification

- Watch ID and governing question
- Audience or decision
- Baseline case and date
- Sources and coverage loci
- Meaningful-change criteria
- Inclusion and exclusion tests
- Regime or event classifications
- Expected cadence if a scheduler exists
- Manual update route if it does not
- Escalation, de-escalation, and stop thresholds
- Privacy and harm constraints
- Baseline checks required for watch-ready posture
