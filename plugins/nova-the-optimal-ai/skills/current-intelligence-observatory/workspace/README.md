# Evidence Atlas

Open Open.cmd on Windows, Open.command on macOS, or index.html directly. No server, installation, network service, or dependency is required. Open a native cd-observatory-case/v1 JSON from **Investigation files**, or use the explicitly synthetic Harbor Lantern example. A comparison baseline is optional.

## Why this interface exists

The skill can reason conversationally about a case. This instrument earns its place by keeping the case's changing assertions, clock types, evidence lineage, rival explanations, and decision boundary visible together while the reader follows an exact native record. It is a projection of the record, not a parallel truth system.

The **Situation** lens puts the latest recorded assessment beside the next human move, open blocker, claims, rival accounts, and dated moments. **Sequence** separates event, observation, publication, and retrieval clocks. **Evidence chains** follows only recorded source IDs, capture IDs, claim capture references, and typed relations. **Challenge** compares recorded hypotheses and contradictions. **Sources** searches origin and custody records. **Compare** shows structural changes by typed ID, with original baseline and current fields side by side. Selecting an item opens its exact native record and references without discarding the case view.

Signal room (default) is a dark navy scanning instrument with grid bearings and a dense signal hierarchy. Evidence folio is a dark olive editorial surface with copper margin rules and a slower reading rhythm. The two environments change composition and material, never case content or capability.

## Evidence boundary and recovery

Every status, confidence label, uncertainty statement, ID, and provenance reference comes from the native case. A missing reference is shown as missing. Similar names, time proximity, repeated reports, or a diagram path never establish identity, independence, coordination, causation, or truth. Structural NEW / CHANGED / NO LONGER REPRESENTED states are not reviewed material-change judgments. The synthetic fixture is dated and has no live verification.

Imported text renders as text. URLs and captures never open automatically. The instrument does not collect, monitor, edit, save, publish, or approve. Data remains in memory and is removed by **Clear private case data** or closing/reloading. No localStorage, browser database, uploads, telemetry, or background watch.

Malformed format, missing typed arrays, duplicate or non-string IDs, and files over 5 MB are rejected without replacing the previous case. After rejection, correct the file and reopen it. Read-only projection cannot substitute for the native collection, semantic challenge, editorial, or publication workflow.
