# Investigate with Current Intelligence Observatory 0.4.0

Start with a question, follow the actual evidence, and leave with an answer whose limits and next observation are clear. The app helps you perform inquiry. It does not browse, reason, monitor or publish autonomously.

## Open your inquiry

Use Python 3.10 or later and a modern browser. Open **Open.cmd** on Windows, **Open.command** on macOS, or run `python launch.py` from the workspace folder. `sh Open.command` works if the macOS execute bit was lost; Linux can use `sh Open.sh`. The launcher opens a loopback address. Direct `index.html` opening does not provide persistent work.

Choose **Start with a question**, write it, and select **Open inquiry**. **Question & search** keeps the intended use, horizon, source boundaries and evidence cutoff beside it. Enter a timezone only when known. **Search the web** and **Search news** open external search pages; they do not fetch or preserve results here. Snippets remain discovery leads. Bring back the actual material.

## Read and connect

Choose **Read material I have** or **Read & connect**. **Add documents or pictures** accepts ordinary files, **Paste text** accepts a passage, and **Browse a source folder** selects an accessible local file. Each source has a stable S-number. Choose its button to read it. **Open retained original** opens its local copy.

**Source context & dates** records title, origin or shared upstream source, URL, publication/update time, event time and scope or currentness limits. The app records the actual time its local copy was added. That is not a claim that the original web page was fetched. A URL alone is not a preserved capture. Two reports with the same origin are not independent corroboration.

Select exact wording in **Source text**, then **Connect evidence to a claim**. Choose a new or existing claim, classify it as a source assertion, observed text, observed event, deterministic result, inference or speculation, and keep its uncertainty visible. Record whether the passage supports, refutes, reports or merely contextualizes the claim. Give a locator and explain why it bears on that exact strength and scope. For an image, describe the actual observation rather than inventing hidden events. **Edit claim & limits** changes your interpretation while keeping source excerpts separate; revisit the links if the claim changes.

## Make time and alternatives useful

**What happened when** keeps event time, when you learned it, supporting source and uncertainty distinct. Event rows remain in recorded order; a local time with no zone is not invented UTC. Source publication and the time a local copy was added are shown separately. Newly learned old information is not a newly occurring event.

**Test explanations** compares a plausible mechanism, what favors it, what challenges it and an obtainable observation that would distinguish it. Do not invent a rival for an uncontested fact. **Next obtainable observation that could change the answer** should name a concrete record or observation, not just more material on the same topic.

## Deliver and return

In **Brief & return**, write **My current answer, with uncertainty**. **Prepare brief from my notes** arranges your answer, claims, exact excerpts, source context, clocks, alternatives and next observation into an editable Markdown draft. It does not generate an independent assessment. Read and edit **Editable brief**, then **Download brief**. **Copy inquiry for my assistant** copies a grounded request and the recorded material; review private content before sharing.

The manual watch fields keep a baseline, meaningful-change threshold, planned return date and exact resumption action. They schedule nothing and send no notification. A written brief is not independently reviewed or publication-ready simply because it exists. Update it when new evidence changes the answer.

## Save and choose a location

**Save work** writes the inquiry outside installed files. The actual path is displayed. Unsaved edits warn before leaving. Atomic saves and revision checks prevent a stale window or app process from silently replacing newer work. If a conflict occurs, **Download working copy** before reloading; restore the draft as an additional inquiry and reconcile deliberately.

**Work folder** lets you browse or enter a **Folder path**. **Use this work folder** opens its work, creating the folder if needed. It does not move or merge your old workspace. A missing or inaccessible remembered path produces a warning and a writable fallback; reconnect the original location through the same control. `python launch.py --data-home "path" --no-browser` selects a folder and prints its local address. The local host may remain running after the browser closes.

Working-copy downloads contain notes and extracted text, not original attachment bytes. **More tools → Restore working copy** adds copies without replacing existing inquiries. For a full backup, copy the entire work folder including `.materials`. Treat source documents and backups according to their sensitivity.

## Source limits and the existing Atlas

Files up to 32 MB are retained. DOCX text omits layout. PDF extraction covers the first 300 pages and two million characters; scanned PDFs remain originals and explicitly need OCR for searchable text. Common text files are readable, and PNG/JPEG/GIF/WebP images display locally. Other formats are retained as attachments without pretending extraction succeeded. A failed import preserves existing work. Unknown attachment formats open as downloads and are not executed by the app.

**More tools → Evidence Atlas** opens the previous detailed native-case viewer in a separate tab. Its typed graph, clock views, review states, examples and snapshots retain their established behavior. Native cases and new working inquiries are separate representations. The app does not mark a native case reviewed or publication-ready. Use the skill and native helpers when the detailed contract serves the task.
