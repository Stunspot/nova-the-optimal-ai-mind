# Observatory Case — portable read-only instrument

Open Open.cmd on Windows, Open.command on macOS (or sh Open.command if permission was lost), or index.html directly. No server/runtime/install or security bypass. Select current native cd-observatory-case/v1 JSON and optional baseline. Labeled Harbor Lantern example is entirely synthetic and snapshot-bound.

## Read the dated case

Claims, Timeline, Relations, Challenge and Sources each have a persistent searchable native-object index, a selected reading record and an exact provenance/challenge pane. Select an object to inspect its status, confidence label, uncertainty and recorded clocks. Inspect a reference to read its exact native object; missing IDs report a gap rather than acquiring an invented source. No embedded command, source URL or capture is opened automatically; imported text renders as text.

Timeline reads recorded events and observations, preserving their native time fields. Relations shows only declared entity/relation objects and source-to-target lanes with their exact typed status. Similar names or simultaneous events do not create links. Challenge keeps hypotheses, contradictions, assessments and blockers distinct. All original fields preserves each full typed record.

Night situation room uses restrained dark signal surfaces and an evidence margin. Briefing paper offers a sober ruled reading composition. Both are snapshot-bound views, not live feeds or evidence certification.

## Compare, then interpret with the owner

Select a comparison baseline and open Delta. Current and baseline objects read side by side with all original fields retained. NEW, CHANGED and NO LONGER REPRESENTED compare native IDs within typed groups; these are structural states, not the Observatory's reviewed material-change taxonomy. Different case IDs remain explicitly displayed, never merged. Use the owner's semantic challenge/watch workflow for interpretation, human decisions and any publication.

Import failures retain the previously selected case. Clear private data removes both current and baseline from memory; reopen the original files to resume. Closing or reloading also discards the view. This instrument has no canonical save, collection, monitoring or publication action.

Malformed format, missing arrays, duplicate IDs and files above 5 MB reject without replacing the prior case. No changes are made to your case. Clear or close to remove in-memory private data. No localStorage, browser database, upload, telemetry or background watch. Browser/assistive-technology/cross-platform acceptance is unobserved until separately exercised.
