Begin with a question

Open this workspace with Open.cmd, Open.command or python launch.py. In the local app, select Start with a question, add actual source material, and connect exact passages to a claim. Keep the kind of claim and its limits visible.

Build a useful answer

Question & search holds the decision and cutoff. Read & connect preserves sources and reasoning. What happened when separates clocks. Test explanations identifies an obtainable discriminating observation. Brief & return prepares editable prose from your own notes and a manual return plan.

Return safely

Save work before leaving. Work folder opens another saved location. A working-copy download retains notes and extracted text; copy the entire work folder to back up originals. A manual watch does not schedule anything.
