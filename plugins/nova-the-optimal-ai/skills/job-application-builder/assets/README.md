# Optional drafting aids

Start with the requested document and supplied evidence. These templates are prompts for an assistant or editor; they are not a mandatory intake form or a quota of final files. Omit sections that do not serve the current application.

For a current saved case use `scripts/new_packet.py` from the skill root and the [v2 packet reference](../references/artifact-contract.md). `source-register.csv` and `evidence-claim-matrix-v2.csv` are the current header templates. The older `source-register.md` CSV and original matrix remain for legacy continuation, not a second current format. The [current fictional example](../examples/current-fictional-packet/case.json) includes both its inputs and selected drafts.

Keep the intake, evidence matrix, gap notes and checklist private. Resume/letter/answer templates are drafting aids; replace every placeholder, choose only requested sections and inspect final applicant-facing prose. Do not export unanswered intake questions, the evidence ledger or this README.
