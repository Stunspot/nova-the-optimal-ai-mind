# Submission checklist

## Vacancy controls

- [ ] Employer and role match the intended vacancy.
- [ ] Posting source and retrieval date are recorded.
- [ ] Deadline and time zone are confirmed.
- [ ] Required files, names, formats, and limits are confirmed.

## Evidence and consistency

- [ ] Every substantive claim is documented, user-confirmed, or a faithful paraphrase.
- [ ] Unsupported claims are absent from final prose.
- [ ] Dates, titles, employers, metrics, credentials, and tools agree across artifacts.
- [ ] Confidential information and unnecessary personal data are absent.
- [ ] Links and work samples open and are approved for sharing.

## User review and attestations

- [ ] The user reviewed the resume.
- [ ] The user reviewed the cover letter.
- [ ] The user reviewed every application answer.
- [ ] Work authorization and other legal attestations were answered by the user.
- [ ] Any accommodation or disclosure decision was made by the user.
- [ ] The user approved the final files.

## External action

- [ ] Submission is still pending.
- [ ] Submission occurred through an authorized action.
- [ ] Confirmation number or receipt was saved by the user.
