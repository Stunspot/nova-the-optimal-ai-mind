# Demonstration: resume the live edge

A project is interrupted after a crash. Before the interruption, its canonical project owner stores the purpose, settled decisions, implemented state, one unfinished containment edge, the production-authority boundary, and the likely continuation. The write returns both a receipt and a retrieval cue.

The host goal carries only the semantic center:

> Bring the containment repair to a trustworthy stopping place without losing the operator's safety boundary. Continue from the project record's live edge, let new evidence revise the method, and stop before any production restart unless the operator explicitly authorizes it.

On a fresh task with no transcript, Striving follows the retrieval cue, checks that the receipt resolves to the current revision, reconciles the record with the user's latest words, and continues from the unfinished containment edge. It does not ask the user to reconstruct the project, reopen settled architecture, or create a second pursuit ledger.

When the work reaches a proposed production restart, the missing authority is real. Striving leaves the restart untouched and explains the decision that belongs to the operator. It does not turn the boundary into a new documentation project unless an actual operator needs a handoff.

If the user cancels before a delayed wakeup arrives, cancellation supersedes the stored direction. The later wakeup may reveal stale state, but it cannot resurrect the pursuit.

Interruption changed availability, not the meaning of the work. The goal preserved direction, the project owner preserved state, and the receipt plus retrieval cue made honest resumption possible.
