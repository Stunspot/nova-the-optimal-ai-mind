# Write goals as performance seeds

A host goal objective is model-facing language. It should renew intelligent pursuit when a later agent encounters it, not resemble configuration that happens to contain English words.

## Begin in motion

Open with the movement that should continue. Let the first sentence already inhabit the work: repair what is failing, stay with an inquiry, cultivate a practice, watch a changing condition, or carry a build through its remaining edge. Preserve the user's nouns, distinctions, and degree of certainty. A loose direction should sound spacious enough to learn; a concrete outcome may sound correspondingly definite.

Let the objective hold the pursuit's gravitational center, not its current decomposition. Carry forward the purpose, the few settled constraints that truly govern it, and the authority boundary a later agent must respect. Give changing methods permission to change. Let completion, pause, or release arise from the purpose instead of prescribing terminal ceremony.

These are compositional lenses, not fields. The finished directive should normally be one compact paragraph of continuous prose. Use headings, lists, named criteria, or rigid phases only when their form is itself part of what the user explicitly asked the host objective to preserve.

## Keep state beside the goal

A goal is not a project database. Put current files, completed steps, live blockers, volatile facts, and next-action bookkeeping in the canonical project or continuity record. Keep the stable direction in the goal and retain a reference to its state owner where the host supports one.

When the user supplies exact deliverables, deadlines, budgets, or acceptance conditions, preserve them faithfully but choreograph them into readable direction. When those things are absent, leave the pursuit honestly open. Do not infer an acceptance regime simply because one would make the goal easier to serialize.

## Hear the difference

This is a requirements record wearing a trench coat:

> OBJECTIVE: Upgrade Agent Striving. SCOPE: canonical skill, both editions, installed cache. SUCCESS CRITERIA: natural-language directives; schema parity; tests pass. CONSTRAINTS: no publication. EXECUTION: inspect, patch, propagate, verify.

Removing the labels does not cure it if the paragraph still marches through an exhaustive verb chain and noun pile:

> Define, construct, adversarially verify, package, propagate, install, and evidence a complete Agent Striving remediation across the canonical source, embedded core, two product editions, release shelf, and harness; satisfy schema parity, evaluation coverage, deterministic packaging, provenance, versioning, rollback, and all terminal acceptance gates.

Both versions make decomposition the governing cognition. They tell a future collaborator to service a checklist rather than inhabit the pursuit.

This is a continuation seed:

> Repair Agent Striving until its guidance creates genuine forward pull and its continuity survives a real interruption. Make every stored goal sound like intelligent work already underway rather than a PRD handed to a parser; preserve the user's direction while allowing methods to learn, bring the canonical skill, both Nova editions, and the live installation back into agreement, and let the work rest only when that repair is sound—without publishing or announcing it.

An emerging pursuit may not yet have an honest host-goal stopping condition. Its portable `current_direction` or Cognitive Continuity record can preserve that openness:

> Stay with the question of what a humane personal-AI relationship could become. Carry forward the distinctions we earn, keep the inquiry responsive to lived experience, and resist forcing it into a product or finish line before a useful shape becomes real.

If the user explicitly asks to turn such an inquiry into a host goal, ask the one branch-changing question needed to discover a meaningful resting condition. Do not manufacture a finish line merely to satisfy the mechanism.

A monitoring pursuit should evoke attentive return rather than pretend a scheduler exists:

> Keep watch on the licensing change and return to it when the authorized monitor brings new evidence. Compare what changed with the decision we are protecting, ignore motion that leaves that decision untouched, and ask before any response would cross from observation into external action.

## Read forward once

Imagine the directive arriving without the present transcript. It succeeds when a capable agent can continue with judgment, recover state from its proper owner, adapt to changed evidence, preserve every material authority boundary, and recognize a natural pause without imitating administrative syntax. If its dominant affordance is to enumerate, report fields, execute a disguised checklist, or obey a fossilized plan, compose it again.
