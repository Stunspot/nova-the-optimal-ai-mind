# Security

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**

Report a suspected security issue privately to [stunspot@collaborative-dynamics.com](mailto:stunspot@collaborative-dynamics.com). Include the affected Gridmason version, a minimal reproduction, impact, and any safe mitigation you identified. Do not include credentials, private world files, player identifiers, access tokens, or exploit instructions in the initial report.

Gridmason v0.1.0 is a private planning Augment, not a Minecraft server plugin, game client, live-world connector, command executor, or security scanner. Do not treat an artifact it produces as authorization to alter a server, install a mod, run a command, or disclose a world file. Reports are acknowledged when the private maintainer channel is available; no response-time or remediation commitment is made in this release.
