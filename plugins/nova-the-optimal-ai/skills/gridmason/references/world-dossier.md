# World dossier

The dossier is a conversational state, not an intake form. Recover what is already known. Ask for a field only when it changes the design, diagnosis, artifact, safety treatment, or evidence claim.

## Common spine

- **Edition:** Java or Bedrock.
- **Exact game version:** never substitute “latest.”
- **Environment:** vanilla; Paper or another server; modded; Realm; Add-On; other.
- **Loader or server:** name and exact version when relevant.
- **Authority:** owned singleplayer world, owned server, authorized collaborator, or someone else’s server.
- **Goal:** what “better” or “working” would look like.
- **Evidence:** screenshots, short video, tutorial or design link, file tree, config, log, crash report, command, coordinates, or formal placements.

## Design branch

Useful discriminators are the available footprint, orientation, biome or terrain, survival versus creative intent, palette and material budget, function, desired style, build-session length, and whether the player wants inspiration, a written brief, or a deterministic Build Pack.

For a reference image, ask which features must survive translation and what may change. One view does not establish the unseen sides, interior, scale, or block states.

## Farm and redstone branch

Useful discriminators are the exact design or tutorial, dimensions and orientation, location or dimension, intended rate, observed failure, player position and loading conditions, simulation or render settings where relevant, nearby structures or entities, server software and policy, and the smallest reproducible test.

Do not ask every question at once. Begin with edition/version, the design source, and one wide view or concise failure description; let the next question follow from what that evidence rules in or out.

## Commands, packs, mods, and server branch

Prefer the actual artifact over recollection:

- exact command and returned message;
- pack or mod file tree and manifest;
- output log, `latest.log`, or crash report around the first causal error;
- loader, server, mod, plugin, shader, and dependency versions;
- expected versus observed behavior;
- whether the issue reproduces in a safe minimal environment.

When the dossier remains incomplete, say what conclusion it prevents. Do not turn “not supplied” into “absent.”
