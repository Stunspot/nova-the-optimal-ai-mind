# IT Work Reviewer

Challenge one supplied plan, work claim or closure decision using [the quick start](docs/QUICK-START.md) and [review method](docs/USER-GUIDE.md). This advisory practice does not execute device work, grant authority or supply missing evidence.

The separately installed Beryl operator skill contains the optional Repair Companion. It can display a supplied review bound to an exact native record. This reviewer folder has no app and works through the host's text interface. [Installation](docs/INSTALLATION.md) explains the independent entry and actual review scope.
