# Review one decision

Invoke `$it-work-reviewer` with the case or plan, the decision it must support and its revision or update time. Specify plan review, work-claim review or repair-closure review. Include the actual evidence and authority limits; the author's explanation cannot replace missing observations.

Expect a scoped verdict, concrete findings, observable closure conditions and the remaining boundary. A bounded plan can pass while execution is still future. An unsupported repair claim cannot. The review does not authorize access, spending or destructive work. If the same assistant wrote the artifact in this context, label its check a self-check.

To display the result in the separately installed Repair Companion, have the host publish the review with its actual author, kind, verdict, text and exact native-record fingerprint using the operator's local bridge. Retain the original review evidence separately. The app rejects a mismatched binding but cannot authenticate independence. A later revision receives no prior review automatically; review the affected claims again when they change.
