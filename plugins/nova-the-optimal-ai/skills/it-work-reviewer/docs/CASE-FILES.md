# Keep review attached to the supplied case

The shared native case schema and helper are included for convenience. From this skill folder run `python -B scripts/validate_case_file.py path/to/case.json --consistency --json`. It checks declared structure and selected consistency, not factual truth or independent review.

Preserve unknown fields, conflicts, prior results and the original symptom. Deleting a failed observation does not repair a stale or unsupported closure. Name the exact case and revision or fingerprint the verdict addresses.

The separately installed Beryl Repair Companion can display the supplied review after the local host binds it to that native-record fingerprint. The reviewer does not maintain a second app or ask the person to construct records. [Review one decision](QUICK-START.md).
