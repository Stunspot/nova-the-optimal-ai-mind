Install, verify, begin

Get to a real choice before continuity gets ideas above its station.

Ludis is a standalone skill directory for manual Codex or Claude Code placement, with a copy/paste fallback. There is no marketplace manifest and no one-click-install claim.

Install for CodexVerify behavior

Requirements

Small package, explicit boundary.

Git or archive

Clone the repository or extract its source archive into the host's skill directory.

Python 3.10+

Required only for deterministic campaign tools. The creative skill is Markdown and JSON.

A skill-capable host

Codex or Claude Code can load SKILL.md; any chat can use the fallback workflow.

Codex

Clone the complete skill, not one decorative file.

Windows PowerShell:

git clone https://github.com/Stunspot/ludis-continuum "$env:USERPROFILE\.codex\skills\ludis-continuum"
python -B "$env:USERPROFILE\.codex\skills\ludis-continuum\scripts\self_check.py"

macOS/Linux:

git clone https://github.com/Stunspot/ludis-continuum "$HOME/.codex/skills/ludis-continuum"
python3 -B "$HOME/.codex/skills/ludis-continuum/scripts/self_check.py"

Restart Codex, confirm Ludis Continuum in the skill list, then run the acceptance prompt below. For project scope, place the repository at <project>/.codex/skills/ludis-continuum/.

Claude Code

Use the same complete package under Claude's skill root.

Windows PowerShell:

git clone https://github.com/Stunspot/ludis-continuum "$env:USERPROFILE\.claude\skills\ludis-continuum"
python -B "$env:USERPROFILE\.claude\skills\ludis-continuum\scripts\self_check.py"

macOS/Linux:

git clone https://github.com/Stunspot/ludis-continuum "$HOME/.claude/skills/ludis-continuum"
python3 -B "$HOME/.claude/skills/ludis-continuum/scripts/self_check.py"

Restart Claude Code. Confirm the skill is listed or /ludis-continuum is available. For project scope, use <project>/.claude/skills/ludis-continuum/. Host UI and invocation syntax may vary by release; observed discovery is the test.

Host-neutral fallback

When discovery is unavailable, degrade honestly.

Open the repository's universal copy/paste workflow, paste it into the conversation, and supply only the campaign material needed. This can deliver the method; it does not make the skill installed or discoverable. It can prepare content for manual transfer, but it cannot execute a local exporter or establish exact-byte evidence without filesystem and tool access.

Verification

File present, package healthy, host discovered, behavior passed: four different claims.

  1. 01PackageRun python -B scripts/self_check.py. Expect PASS for 32 instrument cores.
  2. 02DiscoveryRestart the host and confirm Ludis Continuum in its available skill list.
  3. 03InvocationInvoke $ludis-continuum or the host's displayed command.
  4. 04BehaviorJudge the response against the acceptance criteria below.
Use $ludis-continuum to open a mystery at a mountain observatory whose warning bell rang with no visible intruder. Give me an immediate situation, three materially different choices, and permission to try another move. Do not invent an authoritative rules system. Mark new setting facts as proposed.

Pass only when the response begins in a playable situation, offers genuinely different choices, permits another action, makes no fake rules claim, and keeps new setting facts provisional. If the host does not show the skill, discovery is not verified.

First campaign workspace

Keep campaign data outside the installed skill.

python -B scripts/init_campaign.py C:\Games\MyCampaign --campaign-seed "my stable campaign seed" --title "My Campaign"
python -B scripts/validate_ledger.py C:\Games\MyCampaign\campaign-ledger.json

Initialization creates a v2 ledger with a stable ID derived from the owner-supplied seed and refuses a non-empty destination. The ledger begins empty and private; edit it only with a backup or snapshot and explicit campaign authority.

Expected campaign output: compact GM prep, separately labeled player-safe material, proposed changes, contradictions, checks actually run, approvals still required, and the smallest useful next horizon.

When the campaign is ready to leave the chat window, continue to offline exports and VTT handoffs.
