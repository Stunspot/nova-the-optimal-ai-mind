# Signal Loom

Signal Loom turns supplied reports, research, notes, data, or an existing infographic into a defensible visual story, a mobile-first semantic HTML artifact, and requested platform-native derivatives. Its working state is a resumable Loomfile that keeps sources, claims, narrative, design, interactions, outputs, and reviews inspectable.

Start by invoking `$signal-loom` and supplying the material. “Run this for web + LinkedIn carousel” is enough when the defaults are acceptable.

This folder is the installable skill. Customer installation and first-run instructions are in the release documentation outside the skill folder. Signal Loom never publishes on the user's behalf.
