# First value: Northbridge heat routes

This synthetic example shows a reviewed, not approved, Signal Loom project. It begins with a short brief, a four-row CSV, and messy notes. It produces a source manifest, claim ledger, story spine, visual plan, responsive HTML infographic, ten-panel LinkedIn carousel package, and diagnostics.

Northbridge and every measurement are fictional. The example deliberately includes one unsupported current claim; that claim remains `missing` and is excluded from visible output. The example proves package structure and deterministic checks only when those checks are actually run. It does not prove rendered accessibility, visual quality across browsers, security, professional validity, platform performance, or publication.

Inspect it with:

```text
python scripts/validate_loomfile.py examples/first-value/loomfile
python scripts/inspect_infographic_html.py examples/first-value/loomfile/output/web/index.html
```
