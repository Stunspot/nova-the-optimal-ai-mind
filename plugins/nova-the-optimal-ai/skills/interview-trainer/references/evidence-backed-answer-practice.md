# Evidence-backed answer practice

## Build an answer bank, not a script prison

Use a small set of real examples that can flex across questions. Each answer record should include question IDs, evidence IDs, context, the user's action, reasoning, trade-offs, supported result, learning, and facts requiring confirmation.

STAR can help sequence situation, task, action, and result. SOAR can emphasize situation, obstacles, action, and result. Neither structure substitutes for judgment. The strongest answers make the user's own decision and method visible.

## Evidence rules

Use documented or user-confirmed facts. Do not invent numbers, titles, clients, team size, scope, technologies, or praise. If a result lacks a metric, state the concrete qualitative change. If the user had shared ownership, identify the user's contribution without claiming the whole team's result.

For adjacent experience:

1. name the gap honestly;
2. connect the closest real method or context;
3. explain how the user learned or transferred it;
4. avoid claiming direct experience.

For failures and mistakes, select a real bounded example, own the user's part, explain repair and learning, and avoid fake weaknesses disguised as virtues.

## Method questions

When asked how the user would perform work, cover inputs, priorities, method, checks, trade-offs, escalation, and definition of done. Separate past evidence from a proposed approach.

## Concision and delivery

Aim for a direct first sentence, enough context to understand the stakes, most time on the user's action and judgment, and a clear result or learning. Remove throat-clearing, repeated setup, jargon, and irrelevant chronology.

Delivery coaching may address pace, pauses, answer length, verbal structure, and audible clarity when those are actually observable. Never infer deception, character, intelligence, eye contact, facial expression, or protected traits from unsupported cues.

## Practice progression

1. Retrieve the example without notes.
2. Produce a complete answer.
3. Compress it without losing evidence.
4. Vary the question and preserve the core proof.
5. Explain the method or trade-off behind the action.
6. Handle one skeptical follow-up.

Practice should increase adaptable recall, not memorize brittle prose.
