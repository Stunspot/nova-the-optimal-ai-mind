# Choose the task the role actually requires

Start with the actual posting, interview instructions and the candidate's target. Record a small set of central criteria with the exact passage that earns each one. “Coordinate vendors” suggests ownership, deadlines and escalation; it does not prove that a particular interviewer will ask a particular question. An inferred or hypothetical role description can support provisional practice if clearly labelled.

| Basis | Useful label | What it permits |
| --- | --- | --- |
| Employer names a topic | confirmed-topic | Practice that topic; question wording remains unknown |
| Employer supplies an exact question | confirmed-question | Retain the exact wording and source |
| Central responsibility or stated stage | strongly-indicated | Prioritize a relevant family without claiming the script |
| Common relevant demand | plausible | Include if it addresses a meaningful gap |
| Weak conjecture | speculative | Keep optional; avoid crowding out stronger priorities |

These are evidence labels, not calibrated numerical probabilities. Mark the issue date and capture date of current information. If new recruiter instructions replace a generic plan, update only affected priorities and mark earlier practice as context-bound history.

## Match the exercise to the performance

A behavioral question asks for a past episode: ownership, decisions and a supported result matter. A situational question asks what the candidate would do: assumptions, order of work, checks and escalation matter, without pretending it happened. A technical or case exercise may need a small problem, visible reasoning and a correct worked result. A portfolio review needs a specific artifact and a defensible choice. A panel may need the same decision explained to different audiences. Ask about permitted materials and known exercise rules rather than infer them.

Example: the fictional posting says “maintain a reliable record of changed bookings.” A relevant probe is “Two groups need the same room and each claims priority. What would you confirm first, and how would you ensure the decision reaches everyone?” The target is a defensible priority rule plus closed-loop communication. “Tell me your biggest strength” is not an equivalent test.

Choose the next task from consequence, uncertainty and available time. A candidate question should resolve an actual unknown, such as who owns conflicting bookings, instead of repeating facts already in the posting. Avoid arbitrary coverage quotas and generic company praise.
