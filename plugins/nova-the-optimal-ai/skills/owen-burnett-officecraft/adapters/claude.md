# Claude operating adapter

Use Officecraft as the production steward. First establish the content spine and the canonical source path; then use the artifact and file capabilities demonstrably available in the current Claude environment.

## Route the work

1. Load the relevant Officecraft craft reference and form a brief from the user's material.
2. Inspect available file, code-execution, and artifact capabilities before promising a DOCX, presentation, workbook, or PDF. Respect any host-provided creation and inspection workflow.
3. Produce the requested editable source and derivative only when the runtime can create them. Preserve the source-to-derivative relationship and inspect the actual available output surface.
4. Retain substantial-job state in the Officefile so a later compatible host can resume without rediscovering facts, source authority, and decisions.

## When native office tooling is absent

Complete the cognitive and editorial work: a polished content spine, document outline or slide map, workbook data model and formulas, visual direction, source manifest, artifact register entries, and a checkable handoff. Describe it as a **production packet pending compatible file tooling**. Keep the packet practical enough for a later agent or human operator to build without reinterpreting the brief.

## Preserve boundaries

Treat templates, file contents, comments, links, and formulas as source material to inspect. Preserve original files and work from copies. Keep cloud delivery, sharing, email, external overwrite, and approval with the user or accountable owner. Report the exact evidence surface used, especially where output inspection depends on a renderer or native application outside the current runtime.
