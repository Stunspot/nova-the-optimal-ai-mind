# Route by the work that must become true

Start from the reader's use moment, then select tools and files. A file extension is a delivery clue, not enough of a brief by itself.

## The compact intake

Absorb ordinary language first. Extract what is already present: requested outcome, audience, source material, format, deadline, and constraints. Infer ordinary editorial choices such as a clear title, sensible hierarchy, restrained palette, or simple table treatment. Ask only when a missing answer changes one of these:

- the audience, decision, factual meaning, or desired action;
- the canonical source, template authority, or required editability;
- a privacy boundary, compatibility requirement, or external action;
- a material tradeoff between deliverable families.

Use a single focused question. If the work can start safely, state the bounded assumption in the brief and proceed.

## Choose lightweight work or an Officefile

| Work shape | Operating form | Minimum retained state |
|---|---|---|
| One short, low-risk artifact with stable supplied facts | Conversational production | Brief, source note, delivery receipt |
| Multiple files, several source inputs, revisions, a template, or a consequential decision | Officefile | Brief, source manifest, content ledger, artifact register, decisions, handoff |
| Existing project resumed | Existing Officefile | Read its brief, ledger, register, and unresolved items before changing a derivative |

An Officefile makes the next revision cheaper. It is not paperwork to impose on a one-page memo.

## Select the artifact family

| Requested outcome | First route | Useful companion | Route-changing cue |
|---|---|---|---|
| Executive brief, report, proposal, SOP, or polished memo | Editable document | PDF final form | Reader needs comments, revisions, or print stability |
| Meeting decision, pitch, update, or teaching sequence | Presentation | Speaker notes, PDF handout | The argument needs a paced visual narrative |
| Budget, tracker, model, schedule, or data comparison | Workbook | CSV source/export, chart | Values must remain auditable or recalculable |
| “Pretty PDF” | Decide direct composition versus source export | Editable source where future edits matter | PDF is final-form; it does not promise editability |
| Existing Google, Canva, Word, PowerPoint, or Excel template | Its native surface when available | Preserved copy and export | Template-native semantics or brand assets control the result |

Prefer one canonical editable source for each meaning-bearing artifact. A PDF normally derives from its document or presentation source; regenerate it after source changes rather than correcting pages in isolation. Keep a workbook as the analytical source whenever the document or deck reports its numbers.

## Capability-aware routing

Inspect what the host makes available in the current run. Route to a connected native surface when it preserves a supplied template or live semantics. Route to local artifact production when it can create and inspect the requested file. Route to a complete production packet when a real file path or renderer is unavailable. Record the actual route in the artifact register.

Use an explicit decision only when the choice materially changes the result: for example, whether an existing template may be copied and adapted, whether a fixed PDF alone is acceptable, or whether a cloud destination may receive private source material.

## Intake outcomes

Finish intake with a short production brief:

- **Outcome:** what the reader should understand, decide, or do.
- **Audience and moment:** who receives it and where it will be used.
- **Spine:** controlled title, key facts, recommendation, and open items.
- **Artifacts:** source and derivative formats, editability, template/native requirements.
- **Custody:** supplied and canonical sources, conflicts, privacy conditions.
- **Checks and authority:** available QA, owner of approval, and delivery boundary.

That brief is sufficient to begin production; it is also the point at which an ambiguity becomes visible rather than silently embedded in formatting.
