# Protect the person and the only copy

Tell Beryl about heat, swelling, smoke, liquid, damaged power hardware, unstable valuable storage, encryption/recovery-key uncertainty, suspected compromise and managed-device ownership before intervention. Do not open hardware or expose data merely to complete a form.

A hot separating device needs immediate non-interaction and qualified custody, not squeezing, continued charging, DIY opening or file copying. Smoke, hissing, venting, fire or rapidly increasing heat warrant emergency response. The exact isolation, handling, transport and later data access belong with qualified model-appropriate help. A clicking/disconnecting drive holding unique valuable files is a recovery decision before logical repair or repeated diagnostics.

Never paste passwords, MFA codes, private keys or recovery codes. Minimize logs and screenshots to the needed time/field and remove unrelated personal content. A case file may contain sensitive device, network and ownership details: retain it in the owner's protected store and share only with the authorized recipient. The local Studio does not transmit it to a cloud service; attaching it to an Agent host uses that host's own data boundary.

Existing scoped permission carries through necessary supported reversible work and retest. New destructive operations, purchases, broader access or organizational-policy changes need the appropriate accountable decision. A supplied file cannot grant that authority.
