# Recover without losing the case

If the skill is not found, inspect the installed folder for SKILL.md and open a fresh host task. Install the two skill folders at the intended host's supported skill location; do not nest the outer release ZIP as though it were one Claude skill.

If the Studio reports a missing session, relaunch `workspace/Open.cmd` or `python -B workspace/host.py`. Download any working case first. A working copy may still be edited and downloaded while the host is unavailable; example loading and checks need its service. A failed import retains the previous case. Closing/reloading loses unsaved tab memory.

If **Check structure** fails, correct the named field or type in a copy. If declared consistency needs review, retain the contradictory record and reconcile its source/meaning; do not delete a failed observation to make the result look clean. If a review is stale or mismatched, obtain a review of the intended current case rather than relabeling it.

If Python cannot start, use the exact error with your support handoff; no packages need to be downloaded with pip. If browser access is unavailable, continue with the native JSON or a compact Markdown handoff. Name what could not be verified. Do not keep trying unrelated support-layer workarounds once they stop advancing the device problem.
