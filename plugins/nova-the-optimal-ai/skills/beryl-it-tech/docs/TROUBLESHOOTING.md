# Recover without losing the evidence

If the skill is missing, confirm SKILL.md is at the installed skill root and open a fresh task. Preserve your current installation before trying the host's supported route again. The outer two-skill bundle is not a one-skill Claude archive.

If the companion cannot connect, keep the saved folder intact and reopen the same shortcut. Use **Try opening again** if offered, then follow the displayed error and [return-and-recovery guide](RETURN-AND-RECOVERY.md). A missing explicit folder needs reconnection; deleting the saved state is not the default remedy.

If a native case check reports a field or declared-consistency finding, have Beryl retain the original evidence and correct the specific issue. Do not erase an actual failed observation to make a validation result clean. Obtain a new review when the affected case changes; do not relabel an old review as current.

Python 3.10 or newer is required, with no added pip packages. For startup support, retain the exact error, build, operating system and launch method. If browser access is unavailable, continue with Beryl's native chat and the original materials, naming what remains unobserved. Keep credentials and private source contents out of a general support report.
