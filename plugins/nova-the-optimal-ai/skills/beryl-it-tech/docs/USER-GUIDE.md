# Work the case through the next useful decision

Keep the original complaint and trigger visible. In **Investigation**, compare recorded explanations with the selected test's predicted difference and actual result. A missing prediction or link is missing information, not a negative finding. Historical `state`, `value` and `test` fields remain visible; conflicting old/new fields are called out without changing the native file.

Use **Evidence** to inspect source, kind, time and limits. Use **Recovery & proof** to distinguish a recorded intervention from an original-envelope retest. A successful command, new part or quiet interval alone does not earn “verified resolved.” Check the original task and functions the change could affect; retain the relevant observation window for intermittent trouble.

**Record observed result** opens a recorder. Confirm evidence that the test was performed, enter what happened, choose its evidence kind and name the person, instrument or record. Choose whether this is a new observation/rerun or a transcription correction. Earlier recorded observations are retained in `result_history`; an earlier timestamp is not invented. The recorder changes this tab only. It marks prior verification for reassessment when one exists, and makes an imported review stale. It never decides which cause won.

**Edit case JSON** exposes the complete native record for advanced editing. Applying a material change to the case basis also marks prior verification stale. A deliberate verification-only reconciliation can clear `verification.stale` after you have recorded the new supporting checks; the application cannot authenticate your evidence. Preserve superseded results and explain the changed decision.

Use **IT review** for a separately supplied advisory review. Explicit JSON case/revision mismatches are shown; an unspecified binding remains unknown. Retain the original review file separately. Importing text does not establish independence or authorize action. Download the case before closing or reloading: no browser database or automatic owner-store save exists.
