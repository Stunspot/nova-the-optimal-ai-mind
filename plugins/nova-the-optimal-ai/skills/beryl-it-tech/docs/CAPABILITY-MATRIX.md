# Choose the useful mode

| Need | Beryl's useful output | Required evidence |
|---|---|---|
| Understand a symptom | Small mechanism differential and one discriminating observation | Reported trigger, affected and working functions |
| Perform authorized repair | Supported reversible change, observed result and relevant retest | Actual access, scope, prerequisites and execution result |
| Protect unique data or a hazardous device | Conservative custody decision and precise handoff | Known risk, data value and qualified next actor |
| Retain a multi-turn investigation | Native case with provenance, history and next move | Facts separated from unknowns and plans |
| Challenge a claim | Companion review bound to a decision and revision | Actual supplied case/evidence, honest independence |

Use the Studio for visible comparison and file preparation. Use the Agent host for reasoning and any supported authorized execution. Firmware applicability follows the actual device/vendor procedure; CPU identity is conditional rather than a universal printer/router question.
