# Choose the useful mode

| Need | Useful output | Evidence needed |
|---|---|---|
| Understand a symptom | A small mechanism differential and next discriminating observation | Actual trigger, affected and working functions |
| Observe this Windows PC | A dated three-second CPU-time reading plus RAM, system-volume space and power | The fixed local observation and its available-field limits |
| Compare useful moments | Original values and differences, copied into the existing conversation | Two distinct samples with the same known local identity and human-supplied workload context |
| Read a prepared investigation | Source-linked evidence, rival explanations, planned versus recorded tests and next move | Actual local assistant publication and retained originals |
| Perform supported repair | Authorized intervention and relevant retest through available host tools | Scope, prerequisites, actual execution and observed result |
| Challenge a conclusion | A separately attributed review of the named decision | Exact case/revision and available evidence |

The companion runs only its fixed Windows observation. Beryl's host handles reasoning and supported authorized intervention. Firmware applicability follows the actual device and vendor procedure; CPU identity is not a universal intake question for printers or routers.
