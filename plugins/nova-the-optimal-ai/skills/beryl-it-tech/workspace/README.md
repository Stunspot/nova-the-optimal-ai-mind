# Beryl IT Studio

Open.cmd starts the private loopback bench on Windows; Open.command uses Python 3.10+ on macOS/Linux. No pip dependencies. Reopening the launcher reconnects the exact matching private instance. A working case remains in its original browser tab.

## Follow the fault
Open case imports an existing native Beryl IT case JSON. Explore example opens the explicitly synthetic teaching case; it is not a connected device. The studio holds the reported symptom, original trigger, safe scope and recorded next move above one selected comparison. The diagnostic field shows rival predictions, evidence links, discriminator, and actual result before the secondary indexes. The selected test aligns each linked explanation's recorded prediction with the discriminator and actual result, without deciding the cause. Focus a branch to emphasize it while its rival remains visible; restore equal weight with Compare predictions. Select among tests to keep the comparison in view. Compare predictions exposes all branches together. Test cards name their linked hypothesis IDs and distinguish performed, not performed and unknown performance. Missing evidence references remain visible.

Open an evidence receipt to inspect its source, time, kind and limits inside the comparison; close it to return to the unchanged field. The branch map, linked evidence index and full next-move/custody record open on demand beneath the comparison. Evidence also offers search and kind filters alongside source applicability. Recovery & proof keeps recorded interventions separate from original-envelope retesting, adjacent checks and disposition. IT review accepts a separate JSON, Markdown or text advisory artifact; its operator-selected case binding is not authenticated. Recording a test result requires an explicit performed confirmation, the actual result, evidence kind and named source. It updates only the tab's native working copy, marks a supplied review stale, and asks the operator to reassess the recorded next move. Editing a case marks that review as potentially stale.

## Work on a copy
The original file remains unchanged. The working case lives only in this tab's memory and disappears on close or reload. Download copy prepares a native JSON file with unknown fields intact. Confirm the download reached your files before closing. No browser record store, account action, command execution, authority grant or automatic save is supplied.

Edit case JSON exposes the complete document. Use working copy changes memory only. Invalid JSON, missing identity or malformed supplied collection/container types leave the prior case intact. Cancel or Escape closes the editor without adopting edits. Check structure runs the native validator, not a physical diagnostic test. A structural pass checks the shipped schema: required fields, container and member types, controlled states and populated identity. It does not establish repair. A delayed load or validation response cannot replace or certify a newer working case.

Recorded hazards, scope and stop conditions stay beside the next move. Data, backup & full authority opens the complete custody record. Device & original conditions opens the retained device and complaint, including working functions and recent changes.

## Session and recovery
A missing-session status means reopen the product with its launcher. An existing case can still be edited and downloaded locally while the host is unavailable; sample loading and structural validation need the host. A failed import or request retains the existing case. Download first before replacing edited work.

Duplicate launch matches product, version, exact workspace, runtime bytes and a private process nonce. Health contains no session credential. The credential is held in a HttpOnly SameSite=Strict cookie scoped by product/workspace/port; no owner record is stored in a cookie. Per-user temporary launch metadata is disposable and removed on clean shutdown. POSIX metadata mode is 0600; Windows inherits the user's temporary-directory ACL.

Windows normal launch detaches a CREATE_NO_WINDOW process, verifies identity and opens the browser. Open.cmd falls back to python when py is unavailable. Restart the launcher after reboot. macOS/Linux wrappers are supplied. This interface was inspected in the Windows in-app browser at desktop and 400–520 CSS-pixel widths; that does not establish other hosts or assistive-technology behavior.

Run `python -B host.py --check` for the native sample check and `python -B -m unittest discover -v` for host and schema regression checks. `--no-browser --port 0` runs a foreground instance and prints its private URL; do not publish that credential-bearing URL.
