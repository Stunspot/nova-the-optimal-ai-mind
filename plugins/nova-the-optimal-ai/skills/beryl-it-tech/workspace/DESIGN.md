## The actual visual delta

Mossglass uses an open composition with separately suspended optical panes, asymmetric curved edges, transmitted image detail, diagonal reflection and serif hierarchy. Night Probe changes to a surrounding instrument enclosure, ribbed navigation bed, depressed keys, narrow context column and three-part recessed comparison. Cinder Relay changes to horizontal detents, a broad ceramic body, raised left action module and stacked right prediction wells. Supporting pages and dialogs inherit those materials. Each is visibly different in geometry, hierarchy, light, edges, type, navigation and evidence disclosure.

Scrapbook references were read and viewed as design evidence. New background assets were made with the built-in image-generation tool, copied into the native workspace and served locally. CSS constructs the functioning controls, layout, glass, bevels, wells and shadows. Reference art from the owner's private Scrapbook is not redistributed. ASSET-PROMPTS.md records the generated material assets and prompt set.

The independent review in VISUAL-REVIEW.md passes the inspected bodies. Actual viewport screenshots, including scrolled comparisons, provide the final visual evidence. They do not imply owner approval. Full-page stitching is not used as primary proof because it truncates viewport-fixed backgrounds.

The native case model and existing validation/result/import/export handlers retain their tested semantics. Runtime assets are bundled locally and restricted to three known URLs. No network font or external image service is required at runtime.
