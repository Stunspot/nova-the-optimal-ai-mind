# Nova Knowledge Desk

Open the app to see our registered collections: Our Wiki, recipes, RPG material, Scrapbook, research, archived conversations, and retained knowledge collections. Open a collection, use its named sections or folders, and read its original contents. Saved notes, reminders, and people are browsable without entering a query. The local user's private notes are included; restricted records are excluded.

Search is an optional control. Collections and saved-entry views filter the visible material. Archive search reads conversation text through the existing Giles archive reader. Folder listings page through all visible entries, and archived conversations page through titles and their ordered messages. Long documents have reading controls. Text, Markdown, PDF text, DOCX text, and supported images use Giles' original-source reader. Markdown links stay within their registered collection.

Choose Add to working set to gather pages, passages, reminders, or images while browsing. Working set lets you write a task and copy a request to paste into a chat with Nova. Download reading packet preserves the selected passages, your task and their original locations in Markdown. The working set lasts while this page is open; it does not edit the saved material. Source diagnostics are available under Source details.

## Local operation

Python 3.10+ and the current Nova Operations installation are required. The approved estate's existing path registry selects Nova data. The existing Giles catalog at knowledge/giles/catalog.json supplies collection locations; it is read without initialization or modification. Notes, reminders, and people use their published native commands. Collection files and Personal AI Archive conversations use Giles' bounded readers, including its immutable database snapshots. There is no arbitrary-path, mutation, index-rebuild, or data-migration endpoint.

Use Open.cmd or the existing Nova Knowledge Desk shortcut. A launch authenticates a private loopback session. A same-tab reload keeps the session cookie and returns to the collection home, but clears its working set. If the browser reports a missing session, reopen the launcher. Ember stacks, Survey cloth and Proof press offer three dark reading environments: a warm library, a botanical field folio and a compact editorial press. Collection metadata refreshes when the window regains focus and while it remains visible; an open reading and its working set stay in place. The host validates its current Operations bundle and hashes its workspace plus Giles reader bytes before reconnecting.

Runtime credentials are local and temporary; do not publish launcher output containing the session URL. API and image responses are no-store, require the local session, and enforce loopback host/origin checks. Links cannot read outside registered collections. Retained source files and databases remain authoritative.

The maintained workspace supplies the complete application closure for coordinated Nova edition packaging. Read-only live-source checks and isolated state workflows are distinct from fresh-host installation or model outcomes.
