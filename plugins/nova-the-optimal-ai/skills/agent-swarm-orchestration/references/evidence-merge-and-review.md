# Agent conversation is not evidence

Workers generate findings, artifacts, and actions. The root decides what those outputs establish.

## Keep the verbs honest

- **Assigned:** a worker received responsibility.
- **Dispatched:** the host accepted creation or a turn trigger.
- **Agent-reported:** the worker claimed a result.
- **Observed:** the root inspected the named file, source, output, status, or external state.
- **Reconciled:** intended and authoritative post-state were compared after action or uncertainty.
- **Independently verified:** a separate credible check supported the predicate.

Never promote a worker’s prose directly to observed or verified. A worker may faithfully report a command that ran; the retained command result and named environment establish execution.

## Merge at interfaces

Returns combine cleanly when they use shared vocabulary, compatible scope, explicit assumptions, non-overlapping state ownership, and outputs shaped for a known consumer. When they do not, normalize the interface before debating the conclusion.

For each return, identify:

- the claim and its evidence level;
- source scope, time, version, and authority;
- artifacts touched and their current identity;
- assumptions and missing evidence;
- conflicts with other returns or root observations;
- effect on acceptance and remaining work.

## Resolve the right kind of conflict

- **Factual conflict:** compare primary evidence or run a discriminating observation.
- **Scope conflict:** restate which target, version, environment, or time each claim covers.
- **Assumption conflict:** obtain the observation that would separate the live branches.
- **Artifact conflict:** reconcile current bytes, ownership, and integration order.
- **Recommendation conflict:** compare consequences after factual premises stabilize.
- **Value or priority conflict:** return a bounded decision object to the user.
- **Authority conflict:** stop the affected action until permission is explicit.

Do not average incompatible answers or choose the most confident worker.

## Preserve filesystem reality

Shared workspace access can make agent edits immediately visible. It also makes races immediate. Inspect current bytes, diff, status, tests, and generated artifacts after worker completion. If commit is uncertain, reconcile before another writer begins. A claimed clean merge is not clean until the root observes the relevant state.

## Use independent review without contaminating it

Independent review earns its cost when the merge is consequential, uncertainty remains, or a plausible failure could survive ordinary tests. Give the reviewer the target, intended claim, governing sources, observed evidence, and authority boundary. Withhold the builder’s intended verdict and hidden eval guidance.

Reviewer agreement supports only the reviewed scope and evidence cutoff. It does not grant user authority, certify defect freedom, or establish unexercised host behavior.
