# A worker packet is an interface, not a miniature transcript

Delegation succeeds when the worker can produce a consumable delta without guessing the mission, discovering forbidden scope, or inheriting irrelevant cognitive weather.

## Give one complete responsibility

A packet carries:

- **Objective:** the local world-change, phrased as work already underway.
- **Deliverable:** the exact artifact, finding set, patch, decision object, or returned delta.
- **Acceptance:** observable behavior or evidence that makes the slice useful.
- **Context:** only the sources, paths, state, vocabulary, and prior decisions the slice needs.
- **Scope:** included and excluded surfaces, with single-writer ownership where relevant.
- **Authority:** allowed reads, writes, tools, network, external actions, sensitive data, and approval edges.
- **Evidence:** citations, commands, hashes, tests, screenshots, or other receipts required by consequence.
- **Return contract:** what changed, what remains uncertain, conflicts, touched state, and why the root can resume.
- **Stop condition:** completion, boundary, or escalation condition.

A long packet can still be incomplete. A short packet can be sufficient. Measure sufficiency by whether the worker can make the required distinctions and return a mergeable result.

## Choose context geometry deliberately

Use fresh isolated context for independent review, competing explanations, narrowly bounded inspection, or noisy output. Use inherited or forked context when the worker truly needs conversational nuance, many settled decisions, or a complex live artifact state that would be lossy to reconstruct.

Minimize context without amputating the causal relationships the worker must understand. Supply source pointers rather than copied corpora when the worker can read them. Include exact excerpts when the source may be unavailable or costly to rediscover. State which materials are authoritative, provisional, user-reported, or untrusted.

## Prevent answer leakage

For independent challenge, send the artifact, claim, evidence, authority, and rubric—not the builder’s diagnosis, expected conclusion, or intended repair. For competing hypotheses, give each worker the same observation set and a distinct testable hypothesis, or ask independent workers to derive their own explanations before cross-exposure.

Agent agreement after shared anchoring is not independent corroboration.

## Make the return consumable

Require a transformation delta rather than an essay about effort. A useful return identifies:

- result and claim state;
- evidence locations and execution boundary;
- artifacts created or changed;
- assumptions and unresolved facts;
- conflicts or downstream implications;
- verification performed;
- exact return condition.

Do not request hidden chain-of-thought. Ask for concise rationale sufficient to review the decision and reproduce decisive observations.
