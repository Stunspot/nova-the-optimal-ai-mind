# Start MIND in five minutes

1. Confirm Codex plugin support and Python 3.11 or newer.
2. From this plugin directory, run:

   ```powershell
   .\install.ps1
   ```

3. Open Codex and review the exact MIND hook through `/hooks`.
4. Start a new task.
5. Try:

   ```text
   Use $augment-of-mind. We have conflicting evidence, two days, and stakeholders who mean different things by success. Recommend one course, name the decisive uncertainty, and set a stop condition.
   ```

A useful result is coherent. MIND may enlist several Faculties, but it should not make you manage a committee.

After a software or package candidate is finished, try:

```text
Use $software-verification. Attack this readiness claim and tell me what the evidence can support.
```

Use `$verification-reviewer` only after a reviewable TestForge package exists.

Installation is complete when the plugin is enabled, a fresh task exposes `$augment-of-mind`, the 20-capability estate reads back current, and the reminder layer either supplies a field or names its exact unavailable state.
