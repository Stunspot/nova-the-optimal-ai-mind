# MIND 2.1 package reference

| Path | Purpose |
|---|---|
| `.agents/plugins/marketplace.json` | standalone local marketplace |
| `.codex-plugin/plugin.json` | Codex plugin identity and interface |
| `.mcp.json` | contextual association server registration |
| `hooks/` | prompt-submit hook and configuration |
| `mind_core/` | local SQLite capability and reminder runtime |
| `skills/` | 20 self-contained skill roots |
| `skills/augment-of-mind/assets/` | 20-card bootstrap, associative index, and integrated fingerprint |
| `scripts/` | build, query, install-support, and verification tools |
| `verification/` | evidence boundary for the unqualified 2.1 successor profile |

The 20 skills are one integrator, sixteen Faculties, Capability Promotion, and two TestForge roles. Development caches, private estates, credentials, user databases, and local source inventories do not belong in a customer release.
