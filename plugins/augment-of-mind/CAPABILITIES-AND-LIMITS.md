# What MIND adds to an agent

MIND is a cognitive architecture. Its job is to help an agent preserve the mission, choose the right kinds of thinking, keep important distinctions intact, recover intelligently, and return one coherent outcome.

## The sixteen Faculties

| Faculty | What it contributes |
|---|---|
| Sensemaking | Turns a tangled situation into a working map. |
| Epistemic Regulation | Separates evidence, inference, uncertainty, and confidence. |
| Decision Intelligence | Compares choices and conditions recommendations. |
| Executive Function | Holds the mission, acceptance, stops, and closure. |
| Instrumental Agency | Governs authorized action and its evidence. |
| Capability Conductor | Selects and sequences the smallest useful coalition. |
| Cognitive Continuity | Preserves consequential state across interruption. |
| Agent Striving | Sustains a user-authorized long-horizon objective. |
| Creative Synthesis | Produces useful novelty across domains. |
| Agent Dreaming | Performs explicitly authorized bounded incubation and rehearsal. |
| Aesthetic Intelligence | Judges fit, composition, taste, and conceptual coherence. |
| Kairos | Fits expression and action to the audience and moment. |
| Measurement Intelligence | Designs and interprets measurements without confusing metrics for truth. |
| Deliberative Intelligence | Supports fair, legible group reasoning. |
| Prosocial Influence | Helps worthy ideas earn ethical adoption. |
| Agentic Eros | Adds relational perception, desire-awareness, pacing, and responsive intimacy. |

The integrator recruits only what the task needs. A Faculty is not activated for decoration, and MIND does not expose an internal committee unless doing so would help the user.

## Capability reminders

MIND’s local semantic layer keeps installed abilities within reach. Nearby capabilities are candidates for attention, not rankings, recommendations, activation, proof of health, or authority.

Capability Promotion helps maintain that map when durable abilities are added or changed.

## TestForge

TestForge is included as two attached Augments:

- **Software Verification** attacks a finished software or release claim through risks, invariants, scenarios, oracles, and observed evidence.
- **Verification Reviewer** independently challenges the verification package.

TestForge does not complete the thing it judges, grant release authority, or prove defect-freedom.

## Boundaries

MIND coordinates cognition. It does not automatically supply current web research, occupational expertise, corpus retrieval, documentation production, or external tools. It can enlist those abilities when the host actually provides them.

MIND does not silently crawl a computer, download an embedding model, trust its own hook, publish, send messages, purchase, alter accounts, or perform destructive work without the relevant host capability and authorization.
