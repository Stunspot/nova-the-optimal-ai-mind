# Support

Start with [Start here](START-HERE.md), [Troubleshooting](TROUBLESHOOTING.md), and [Capabilities and limits](CAPABILITIES-AND-LIMITS.md).

For a package bug or documentation problem, open an issue at [Stunspot/augment-of-mind](https://github.com/Stunspot/augment-of-mind/issues). Include the version, host, operating system, smallest safe reproduction, observed result, and expected result. Remove private prompts, credentials, customer data, and database contents.

For a security or privacy concern, follow [Security](SECURITY.md) instead of posting sensitive details publicly.

This open-source release has no service-level agreement. Issues are useful evidence, not a promise of a response time or custom implementation.
