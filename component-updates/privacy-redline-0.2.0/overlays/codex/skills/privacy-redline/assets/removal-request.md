# Review a removal request

Use this optional worksheet inside the existing Queue when a batch, handoff or interruption needs it. Use redacted references and field names. Keep actual identity values in the person's protected entry path.

Describe the unwanted exposure and the intended effect.

Identify the subject's authority and the basis for matching each public listing, including any contradiction.

Name the operator, verified official route and delegated recipient. Identify the policy or regulator source and check date.

State the request type, permitted field categories, expected consequence, and how the result will be checked.

Retain the user's applicable authorization, recipient scope, duration, recurrence if any, and cancellation condition.

Record preparation, possible dispatch, submission or response as observed. Preserve an uncertain delivery instead of repeating the request blindly.

Describe each outcome precisely, its evidence and residual exposure. Include the next useful action or recheck condition.
