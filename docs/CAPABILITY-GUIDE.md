# Choose the right capability

You normally do not need to choose. Ask Nova for the outcome you want; MIND recalls nearby capability handles and Nova opens only the useful ones. Name a skill when you want its responsibility explicitly.

## Core mind

| Need | Capability |
|---|---|
| One coherent collaborator across domains | `$nova` |
| Several cognitive transformations combined | `$augment-of-mind` |
| One specific cognitive transformation | the relevant MIND Faculty |
| Model-facing prompt design | `$promptcraft` |
| Adversarial verification of finished software or releases | `$software-verification` |
| Independent challenge of verification evidence | `$verification-reviewer` |

MIND has exactly sixteen Faculties: Aesthetic Intelligence, Agent Dreaming, Agent Striving, Agentic Eros, Capability Conductor, Cognitive Continuity, Creative Synthesis, Decision Intelligence, Deliberative Intelligence, Epistemic Regulation, Executive Function, Instrumental Agency, Kairos, Measurement Intelligence, Prosocial Influence, and Sensemaking.

TestForge's two skills ship inside the MIND plugin but are not Faculties.

## Research, evidence, and knowledge

| Need | Capability |
|---|---|
| Current multi-source investigation | `$omnara-deep-research` |
| Answer from an authorized corpus | `$retrieval-intelligence` |
| Challenge retrieval and citations | `$retrieval-reviewer` |
| Decide canonical source and provenance | `$rupert-giles-knowledge-steward` |
| Maintain an answer as evidence changes | `$answerlayer` |
| Track a changing topic and watch conditions | `$current-intelligence-observatory` |
| Reduce personal-data exposure | `$privacy-redline` |

Research finds evidence. Retrieval searches a bounded corpus. Knowledge stewardship decides what is canonical. AnswerLayer maintains a durable answer. The Observatory watches change. Similar nouns; different jobs. Tiny distinctions, enormous reduction in nonsense.

## Making and repair

| Need | Capability |
|---|---|
| Change software in a live repository | `$agentic-coding` |
| Create office documents, sheets, slides, or packets | `$owen-burnett-officecraft` |
| Review an office artifact independently | `$officecraft-reviewer` |
| Diagnose and repair user IT problems | `$beryl-it-tech` |
| Review IT repair evidence | `$it-work-reviewer` |
| Turn evidence into a visual story | `$signal-loom` |
| Reduce AI cognition cost without lowering acceptance | `$ai-cognition-cost-optimizer` |

Makers work before reviewers. TestForge receives a finished software or release candidate. It is not the workshop where the candidate is completed.

## Memory and people

| Need | Capability |
|---|---|
| Explicit low-pressure reminder pin | `$corkboard` |
| Governed context about a person or relationship | `$dunbar` |
| Consequential mission state across interruption | `$cognitive-continuity` |
| A durable user-authorized long-horizon objective | `$agent-striving` |

A pin is not a scheduled reminder. A person record is not permission to scrape. Conversation context is not proof of durable memory.

## Play and learning

| Need | Capability |
|---|---|
| Minecraft design, diagnosis, or exact approved build specs | `$gridmason` |
| Games, roleplay, characters, worlds, and fiction | `$ludis-continuum` |
| Adaptive language practice and coaching | `$lex-foster-language-companion` |

Gridmason is for Minecraft evidence and builds. Ludis is for games and fiction broadly. Lex coaches learning rather than merely translating.

## If several capabilities fit

Let Nova keep the mission and use the smallest sufficient set. Operators create; reviewers challenge; MIND integrates cognition; Nova returns the result. A handle in a reminder field is only nearby—it is not automatically selected, loaded, healthy, or authorized.
