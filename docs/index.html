Codex-first integrated release

Install. Inspect. Verify. Then start fresh.

1. Download the latest Nova + MIND Free ZIP. 2. Ask Codex to install and enable both plugins. 3. Inspect the exact MIND hook before trusting it. 4. Run verify-install.ps1 with Codex closed. 5. Start a new task and confirm discovery.

You need Codex plugin support, PowerShell, Python 3.11+, and local Ollama with qwen3-embedding:0.6b. Model weights are not bundled or silently downloaded.

Claude-compatible hosts receive structurally verified per-skill archives—not Codex’s shared database, hook, or automatic reminders.
