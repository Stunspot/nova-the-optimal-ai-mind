Rights custody

Licenses travel with the product

Nova Free uses the standard Collaborative Dynamics public-Augment split license: MIT for deterministic software and schemas, and CC BY-ND 4.0 for authored Augment material. Authentic, unmodified distributions must keep the supplied attribution, notice, trademark policy, provenance, and component notices attached.

CC BY-ND permits sharing the licensed authored material with attribution, but it does not permit distributing modified versions of that material. Read the included LICENSE.md for the exact product scope and the official CC BY-ND 4.0 legal code for the governing terms.

Complete product packet

The customer root and both complete host plugins carry LICENSE.md, ATTRIBUTION.md, NOTICE.md, TRADEMARKS.md, PROVENANCE.md, and THIRD-PARTY-NOTICES.md. The source lock records their hashes.

Individual Claude skills

Every detachable folder and ZIP carries a nova-free-rights directory. Preserve it with the skill. TestForge, Agent Swarm, Job Application Builder, and Interview Trainer also carry the relevant component-specific packet inside that directory.

Component terms that remain

TestForge and Agent Swarm retain their included split-license and provenance packets. Existing MIT grants remain available for MIT-released components. Current Intelligence Observatory retains its embedded CC BY 4.0 attribution notice. The Nova Free product license supplies the public-edition authorization for earlier same-owner components that came from narrower standalone contexts.

Third-party boundary

Third-party publications, facts, names, links, services, and marks retain their own rights. Nova Free does not claim ownership or endorsement. The source map identifies no external third-party runtime code repository in this edition.

Permission is not publication: the included licenses permit qualifying redistribution. They do not assert that a tag, push, GitHub release, directory submission, website deployment, or announcement occurred.
