Troubleshooting

Preserve the exact symptom

Record product version, package hash, host and operating system, installation route, command or request, sanitized error, and the state that actually failed.

Plugin not found

codex plugin marketplace add "<extracted package>/codex" --json
codex plugin list --available --json
codex plugin add nova-the-optimal-ai --marketplace collaborative-dynamics-nova-free --json
codex plugin list --json

Do not delete other marketplaces as a shortcut. Start a new task after catalog changes.

Specialist absent

Compare the installed plugin's skills directory with LOADOUT-MANIFEST.json. Then name the missing specialist explicitly in one minimal activation request. A directory name proves presence, not discovery or invocation.

Persistent service unavailable

$nova-operations Show status for my existing Free Nova estate.
Read only; do not initialize, repair, or move anything.

A healthy read-only response reports the registry state and exact selectors without writing. To create an estate, name an absolute customer-controlled root and ask Nova Operations to show every proposed selector and write before approval.

Upgrade collision

Stop before replacing the shared plugin ID. Record the installed version and state, then follow the controlled upgrade and rollback route.

Package mismatch

Compare the archive digest and extracted SHA256SUMS.txt. If you also have the source repository, rebuild and run its verifier against the extracted package. Preserve the failing artifact rather than editing a ZIP in place.

Prepare a bounded support report.
