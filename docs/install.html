Codex requirements

  • Codex with plugin support
  • PowerShell
  • Python 3.11 or newer
  • Ollama serving qwen3-embedding:0.6b
  • An empty approved database path, or a deliberate upgrade plan

The package does not download model weights or silently replace another Nova/MIND source or database.

Normal installation

  1. Download the governed nova-mind-free-v2.1.3.zip from the latest published release.
  2. Attach the ZIP to a Codex task.
  3. Ask Codex: Install Nova + MIND from this ZIP and turn both plugins on. Ask before replacing any existing Nova or MIND installation.
  4. Review the proposed changes.
  5. Open Settings → Hooks, inspect the exact prompt-submit hook, and decide whether to trust those bytes.
  6. Close Codex and run the verifier from the extracted release.
.\verify-install.ps1 -OutputPath .\nova-mind-install-verification.json

Interpret the verifier correctly

A PASS confirms the marketplace, enabled plugin versions, database integrity, active estate, forty-one cards, 246 vectors, and a semantic probe against a temporary copy. It does not prove hook trust, pre-turn delivery, model attention, or correct use.

Start a new task and enter:

$nova Help me make a concrete first move on this objective: [your objective]. Separate what you know from what you are assuming.

Expect one coherent useful response. If the handle is missing, record a discovery failure; a copied folder alone is not installation proof.

Manual and Claude paths

If Codex cannot install the attached archive, extract it and run .\install.ps1. For full prerequisites and recovery, read the manual Codex guide.

For Claude-compatible hosts, upload selected archives from claude/zips/ and begin a new conversation. Read the portable-skill guide.
