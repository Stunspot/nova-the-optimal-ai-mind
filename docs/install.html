Get Nova Free

Three steps to your agent.

Nova is one complete package for Agent Skills-compatible hosts. Ordinary use needs no local model, database, daemon, embedding service, prompt hook, or separate Nova account.

1

Download

Get the latest Nova Free release from GitHub and extract the customer ZIP to a stable folder.

Open the latest release
2

Install

Use the complete Codex or Claude-compatible route your host supports. Install one Nova plugin, not twenty-seven loose pieces unless your host genuinely requires folders.

3

Meet Nova

Start a fresh task and say: “Nova, help me turn this mess into something useful.” If she answers as Nova Free 3.1.2, your agent is awake.

Cost boundary: the Nova package costs nothing. Your compatible host, model, network tools, or connected services may have their own terms or charges.

Codex

Install from the local marketplace

Add the extracted codex directory as a local marketplace, install the single plugin, and inspect the host’s observed state.

codex plugin marketplace add "<extracted package>/codex" --json
codex plugin add nova-the-optimal-ai --marketplace collaborative-dynamics-nova-free --json
codex plugin list --json

Then restart or open a new task as your host requires and explicitly invoke $nova once. Files being present does not prove discovery, enabled state, or live behavior.

Claude-compatible hosts

Use the complete bundle when possible

The package supplies the complete bundle at claude/nova-the-optimal-ai, plain skill folders under claude/folders, and deterministic skill ZIPs under claude/zips. Prefer the complete bundle when your host supports it. Individual skills are a compatibility route, not a build-your-own-Nova hobby kit.

Memory and continuity stay optional

Nova works immediately from the active conversation and materials you provide. If you later ask for durable projects, continuity, reminders, people context, or personal notes, Nova Operations proposes a customer-chosen estate outside the host’s own configuration area and asks before writing.

Upgrading an older Nova Free

Free 2.x and 3.1.2 use the same nova-the-optimal-ai plugin ID. Extracting both is safe staging; installing 3.1.2 replaces that active binding. Preserve the previous package and any Continuity data first, then follow the upgrade and rollback guide.

Keep the rights envelope. The complete bundle carries its public license and provenance at the root. Individual folders and ZIPs carry the same packet under nova-free-rights. Preserve it when copying or redistributing the authentic package.
