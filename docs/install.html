Get Nova Free

Three steps to your agent.

Nova is one complete package for Agent Skills-compatible hosts. Ordinary use needs no local model, database, daemon, embedding service, prompt hook, or separate Nova account.

1

Download

Open the 4.3.1 release and download Source code (zip), or clone its tag. Extract it to a stable folder and preserve the complete repository. Prebuilt customer and host ZIPs are verified locally; their GitHub attachments are pending after an upload failure.

Download Nova Free 4.3.1
2

Install

Use the complete Codex or Claude-compatible route your host supports. Install one Nova plugin, with 28 native skills; use individual folders only when your host requires them.

3

Meet Nova

Start a fresh task and say: “Nova, help me turn this mess into something useful.” Confirm the host lists Free 4.3.1 as installed and enabled, then verify a useful Nova invocation.

Cost boundary: the Nova package costs nothing. Your compatible host, model, network tools, or connected services may have their own terms or charges.

Codex

Install from the local marketplace

For the current source download, add the extracted repository root as the local marketplace. Then install the single plugin and inspect the observed version and enabled state. The built customer kit uses its outer codex directory instead.

codex plugin marketplace add "<extracted source repository>" --json
codex plugin add nova-the-optimal-ai@collaborative-dynamics-nova-free --json
codex plugin list --json

Then restart or open a new task as your host requires and explicitly invoke $nova once. Files being present does not prove discovery, enabled state, or live behavior.

Claude-compatible hosts

Use the complete bundle when possible

The source download supplies the complete plugin at claude/nova-the-optimal-ai. Use that full folder with the repository license and notices. The built customer kit also supplies detachable rights-wrapped skill folders and ZIPs; those are separate from this source fallback.

Memory and continuity stay optional

Nova works immediately from the active conversation and materials you provide. If you later ask for durable projects, continuity, reminders, people context, or personal notes, Nova Operations proposes a customer-chosen estate outside the host’s own configuration area and asks before writing.

Repair an existing OSINT workbench too

Updating Nova files does not update a separately installed Python environment. Follow the security upgrade guide before the next optional Observatory acquisition. Preserve diagnostic refusals; repair the selected dependency instead of bypassing its guard.

Upgrading an older Nova Free

Earlier Free editions and 4.3.1 use the same nova-the-optimal-ai plugin ID. Extracting both is safe staging; installing 4.3.1 replaces that active binding. Preserve the previous package and any Continuity data first, then follow the upgrade and rollback guide.

Keep the rights envelope. The complete bundle carries its public license and provenance at the root. Individual folders and ZIPs carry the same packet under nova-free-rights. Preserve it when copying or redistributing the authentic package.
