Installation

Install the complete Nova

Use one host route. Preserve any existing Nova state, install the complete candidate, then verify a real invocation in a new task.

Codex local marketplace

  1. Extract the customer ZIP to a stable folder.
  2. Add its codex folder as a local marketplace. That directory contains .agents/plugins/marketplace.json.
  3. Install the single nova-the-optimal-ai plugin.
  4. Start a new task and explicitly invoke $nova.
  5. Confirm Nova identifies the Free 3.0.0 edition and can route a simple request.
codex plugin marketplace add "<extracted package>/codex" --json
codex plugin add nova-the-optimal-ai --marketplace collaborative-dynamics-nova-free --json
codex plugin list --json

Do not call the installation active merely because files are visible. Installation, discovery, enabled state, invocation, and healthy behavior are separate observations.

Claude-compatible hosts

The customer package supplies three routes: a complete bundle, twenty-five plain skill folders, and twenty-five deterministic skill ZIPs. Prefer the complete bundle when the host supports plugin-style packages; use individual skills only when that is the host's actual contract.

After copying files, start a new task and verify a live Nova invocation. Individual folders do not recreate unsupported host features by wishing very sternly.

Suggested installer instruction

Install Nova the Optimal AI Free as one complete plugin.
Ask before replacing another governing Nova installation.
Do not configure persistent data unless I separately request it.

Optional state

Ordinary use needs no state setup. If you want durable continuity, reminders, or people context, ask Nova to initialize an estate in a customer-chosen directory. Nova Operations must show the proposed path and obtain approval before writing.

Upgrading an older Free edition

Extract and inspect 3.0.0 beside the older package first, but do not call that an installed side-by-side upgrade. Free 2.x and 3.0.0 use the same nova-the-optimal-ai plugin ID, so installing 3.0.0 replaces that plugin binding. Preserve the old package and Continuity data for rollback, obtain approval for the replacement, and inspect any old MIND hook or local-model setup separately.

Use the repository's upgrade guide for the complete migration boundary.

Publication boundary: the current repository candidate is for local product review. Do not redistribute it until the recorded component-license gates are resolved.
