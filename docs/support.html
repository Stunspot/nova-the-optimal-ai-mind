Recovery beats ritual reinstalling

Keep the symptom. Change the premise.

Record the exact state before changing anything. Presence, discovery, hook trust, delivery, model use, and specialist behavior fail for different reasons.

Common recovery branches

Plugin missing

Confirm the marketplace and both enabled selectors. Restart the Codex surface if it caches discovery, then start a new task.

Hook unavailable

Inspect the installed bytes, then check Python, the exact database path, Ollama endpoint, and named embedding model.

Existing installation

Stop. The installer intentionally refuses silent replacement. Record selectors and preserve the database before a deliberate upgrade.

Reminder degraded

Preserve the failure code and receipt. Fix the dependency before retrying; do not ask the model to reconstruct the field.

Use the complete troubleshooting guide.

Update or roll back

Record codex plugin marketplace list --json and codex plugin list --json, back up valued state, keep one enabled Nova and one enabled MIND source, and inspect changed hook bytes again. The release has no automatic legacy-estate merger. Rollback is complete only after the restored versions are enabled and discovered in a fresh task.

Remove and clean up

Remove only the exact plugin selectors. Uninstallation does not delete the SQLite database, Ollama model, verification report, downloaded archive, generated artifacts, or Claude installations. Resolve every exact path and make those deletion decisions separately.

Read upgrade, rollback, removal, and cleanup.

Ask for support

Open an issue at Stunspot/nova-the-optimal-ai-mind with versions, host, OS, smallest safe reproduction, complete error, expected result, and the evidence state that failed. Remove credentials, private prompts, customer data, databases, sensitive paths, and raw receipts.

Security and privacy reports belong in the repository’s private security channel. This open-source release has no SLA or custom-implementation entitlement.

Contribute

Issues and pull requests are welcome. Read the real source before changing claims. Preserve provenance, the Nova/MIND product invariant, the sixteen-Faculty boundary, evidence states, customer links, deterministic release behavior, and unrelated local work. Documentation changes require new content-bound review receipts.
