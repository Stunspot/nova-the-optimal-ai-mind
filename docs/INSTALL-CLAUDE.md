# Claude-compatible installation

The customer package offers three Claude-compatible shapes: the complete claude/nova-the-optimal-ai bundle, one folder per skill under claude/folders, and one deterministic archive per skill under claude/zips.

Prefer the complete bundle when the live host supports multi-skill plugins. If it supports only individual Agent Skills, install selected folders or ZIPs without claiming complete-edition composition. Every detachable folder and ZIP contains a nova-free-rights directory; preserve that directory when copying or redistributing the skill. TestForge, Agent Swarm, and the career pair also carry their relevant component notice packet inside that envelope.

Host conventions and limits change. Verify the current host's actual import route, accepted archive shape, discovery, permissions, and one real invocation. Static byte parity with Codex does not prove behavioral parity.

Nova Operations persistent services still require Python 3.10 or newer available to the harness and a separately authorized estate root.
