# Update Nova 4.3.1 safely

This release carries the CVE-2026-111497 repair for the included optional network helpers. Keep the complete edition together and update the existing installed plugin or skill route. Preserve your separate data homes and saved work. The edition roster, ambient MIND and disabled companion-app presentations retain their accepted behavior.

## Existing Observatory workbench

Updating the Nova files does not update a separately installed Python environment. From the new Observatory skill folder, run:

```text
python scripts/upgrade_osint_security.py --home "PATH_TO_EXISTING_OSINT_HOME"
```

You need uv, package-index access and the existing isolated Maigret environment. The result reports `upgraded: true` and `native_curl_decoding: false`. Configuration, credentials, reports and site data stay in place; the prior entrypoint is saved under `security-backups`. Use Nova's packaged bridge or the workbench command for subsequent queries. The raw Maigret executable bypasses the guarded transport. A current curl-cffi package may still embed old Brotli; the supported route disables its native content decoding and uses checked Python Brotli 1.2.1. Preserve any unsafe-decoder refusal and repair that selected environment before querying.

## Confirm the update

Check the installed edition version and invoke the included capability through its installed route. A copied package is distinct from a repaired optional environment. A failed capture check needs no vault reset or continuity migration. If startup fails, retain the diagnostic and repair the selected dependency; do not bypass the guard with another raw helper. Fixed Node 24.22.1 can still display Brotli 1.2.0 because the security fix was backported; the selected runtime check uses its actual fix marker.
