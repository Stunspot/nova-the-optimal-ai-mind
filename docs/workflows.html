First value

Bring the work you already have.

No forty-one-item onboarding ritual. Ask for the outcome; supply the evidence and authority the work actually needs.

Decide from messy evidence

Input: notes, options, constraints, dates, and the decision you own.

$nova Turn these notes into a decision. Separate evidence, assumptions, unknowns, and authorization. Recommend one option with reversal conditions.

Expected output: a working frame, material unknowns, comparable options, recommendation, confidence boundary, and next evidence-producing move. MIND may enlist Sensemaking, Epistemic Regulation, and Decision Intelligence; it should still return one answer.

Build and challenge a software release

Input: repository, defect or feature, acceptance criteria, and allowed test environment.

$nova Fix this repository issue. Preserve unrelated work, test the smallest coherent change, then use TestForge on the finished candidate.

Expected output: scoped implementation, observed test results, changed files, residual risks, and an adversarial readiness verdict. TestForge does not repair the candidate while judging it or claim unexercised environments passed.

Investigate a changing question

Input: research question, date boundary, acceptable sources, budget, and output audience.

$nova Investigate what changed since this baseline. Preserve contradictory evidence and cite every material current claim.

Expected output: a sourced, resumable evidence case or brief with observations, claims, inferences, gaps, and currentness. Current web work requires a real browser/search capability; Nova does not invent browsing.

Create an office artifact

Input: source material, intended reader, artifact type, brand/accessibility needs, and publication boundary.

$nova Turn these notes and figures into an accessible leadership brief and PDF. Keep unsupported claims out and inspect the final render.

Expected output: source inventory, designed artifact, inspection evidence, accessibility notes, and handoff. File creation requires the host’s document/PDF tools; a Markdown draft is not a verified PDF.

Hold a long-running mission

Input: explicit objective, acceptance, stop conditions, authority, and desired cadence.

$nova Hold this objective until completion. Preserve decisions, change strategy after repeated failure, and tell me the exact blocker if authority or evidence runs out.

Expected output: durable goal custody when Agent Striving is actually available, bounded checkpoints, changed-route recovery, and explicit closure. Conversation context alone is not proof of persisted state.

Practice a language for a real situation

Input: language pair, learner level, situation, correction preference, and consequence level.

$lex-foster-language-companion Help me rehearse this customer call in Spanish. Correct only errors that change meaning, then give me a short recap.

Expected output: adaptive practice, selective correction, pragmatic/cultural notes bounded by region and evidence, and a compact session recap. Lex is not a certified interpreter for legal, medical, immigration, or safety-critical communication.
