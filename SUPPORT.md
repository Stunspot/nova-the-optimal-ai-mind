# Support

Start with [Troubleshooting](docs/TROUBLESHOOTING.md). If you still need help, open an issue in the public repository with enough information to reproduce the problem safely.

Include the exact command or request, the full error or surprising result, your operating system, Codex or Claude version, Python version, and the smallest reproduction you can share.

Please remove credentials, private prompts, personal data, and sensitive file paths. Do not attach a local MIND database or hook receipts to a public issue without inspecting them first.

For a security or privacy concern, follow [Security](SECURITY.md) instead of posting exploit details publicly.
