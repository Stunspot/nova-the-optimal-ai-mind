# Support

Begin with [Troubleshooting](docs/TROUBLESHOOTING.md). If the problem remains, report:

- the exact command or prompt;
- the complete error or unexpected output;
- operating system and shell;
- Codex or Claude version;
- Python version;
- exact plugin selectors and enabled state;
- active snapshot ID and qualification state when reminders are involved;
- what was present, installed, discovered, attempted, returned, or verified;
- the smallest reproduction that preserves the failure.

Redact credentials, private file contents, personal data, and sensitive absolute paths. Do not post a Core database or hook receipts publicly without inspecting them first.

Project support and issue tracking will live in the canonical GitHub repository after publication. Until then, keep the report with the private release candidate rather than filing it against the frozen contest repository.
