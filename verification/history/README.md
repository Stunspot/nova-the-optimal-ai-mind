# Verification history

This directory preserves evidence from earlier Nova Free product lines and superseded local candidates. It is historical context, not current Free 3.0.0 qualification evidence.

The `free-2.x` subtree records the retired two-plugin, hook, embedding, and associative-runtime architecture. `free-v3-pre-review-6151da1` preserves the first 3.0.0 package/evidence cycle rejected during independent process review. Current evidence lives directly under `verification/` in the explicitly versioned Free 3.0.0 ledgers. Never use a historical PASS to claim that the current package, host behavior, or public distribution is ready.
